20. 給与仕訳連携登録¶

外部の給与システムからプロジェクト原価管理モジュールに給与仕訳を取り込む際の仕訳設定情報を登録します。

20.1. 着手条件¶

プロジェクト登録までの作業を終えていること。

20.2. 実行手順¶

Biz∫会計管理者アカウントでポータル画面にログインし、以下のメニューより「F5:新規」を押下し、給与仕訳連携設定を登録します。

  • メニュー

    Biz∫ 会計
  プロジェクト原価管理
    業務連動
      マスタメンテナンス
        給与仕訳連携設定管理

    コラム

    一括登録を行う場合、一括取込マニュアルの給与仕訳連携設定を参考に取込ファイルを準備し、同メニューの「SF5:一括取込」ボタンより登録します。

20.3. 完了条件¶

登録した給与仕訳連携設定が、同画面から検索できることを確認します。プルーフリストを取得し、登録内容を確認することも可能です。

20.4. 給与仕訳取込CSVについて¶

20.4.1. 概要¶

  • 給与システムからは個人別の給与明細のCSVを取り込むことを想定しています。

20.4.2. CSVの項目について¶

  • CSV内には以下の情報が必要となります。

    項目

    内容

    備考

    氏名コード

    社員を特定するコードを設定します。

    氏名コードの桁位置はパラメータで設定します。

    社員区分

    役員/一般社員/嘱託を区別するコードを設定します。コード値は分析コード登録(プロジェクト原価管理)で設定します。

    役員、一般社員、嘱託毎に勘定科目を変えることができます。一般社員は労務費原価差額計算の対象となります。社員区分の桁位置はパラメータで設定します。

    組織コード

    社員の所属組織を設定します。

    給与仕訳の計上組織となります。人事組織と会計組織が異なる場合、変換表を用意することで変換可能です。

    給与支給日

    給与支給日を設定します。

    給与支給日をもとに計上日を算出します。

    ランク決定項目

    ランクを決定するための情報を設定します。

    ランク区分登録で登録します。

    支給項目

    支給項目毎の金額を設定します。

    支給項目毎に勘定科目を割り当てます。給与と賞与を同じレイアウトで取り込むため、勘定科目を変える場合は支給項目（CSVの桁位置）を変える必要があります。

    控除項目

    控除項目毎の金額を設定します。

    控除項目毎に勘定科目を割り当てます。

    支給額

    支給額を設定します。

    支給額に対して勘定科目を割り当てます。

    会社負担の社会保険料の項目

    項目毎の金額を設定します。

    項目毎に借方の勘定科目を割り当てます。

コラム

組織取得方法、社員取得方法、プロジェクト取得方法のいずれかに「3:変換」を設定する場合、変換元の項目には必ず値を設定してください。

未設定の場合には、変換することができず、変換表に存在しない旨のエラーが出力されます。
