.. _FMS_introduce_workflow-import:

===================================================
|IM_WF| マスタ登録
===================================================

|FMS| の用いるワークフロー定義を |IM| へ登録します。


.. _FMS_introduce_workflow-import-startConditions:

着手条件
===================================================

:ref:`FMS_setup_production_environment` の :ref:`FMS_setup_bizSetting` までを終えていること。

.. note::

  ${パブリックストレージパス}/im_workflow/data/${テナントID}/import_export/ にワークフロー定義が配置されています。

.. _FMS_introduce_workflow-import-do:

実行手順
===================================================

.. _FMS_introduce_workflow-import-do-import:

インポートの実施
---------------------------------------------------

|FMS| 管理者アカウントでポータル画面にログインし、 `テナント環境のセットアップ`_ で配備されたフォルダにチェックを入れ、インポートを実施します。

* メニュー ::

    ワークフロー
      ワークフロー管理者
        インポート／エクスポート
          インポート


.. _FMS_introduce_workflow-import-endConditions:

完了条件
===================================================

以下の各定義メニューからワークフロー定義がインポートされていることを確認します。

* メニュー ::

    ワークフロー
      ワークフロー管理者
        マスタ定義
          コンテンツ定義
          ルート定義
          フロー定義
          案件プロパティ定義
          一覧表示パターン定義
          フローグループ定義
