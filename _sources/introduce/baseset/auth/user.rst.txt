===================================================================
権限グループとユーザの関連づけ
===================================================================

権限グループに所属させる対象のユーザを指定します。指定したユーザには、権限グループに所属する権限が付与されます。

.. _FMS_introduce_baseset_auth-user-startConditions:

着手条件
===================================================

権限グループ登録を終えていること。

.. _FMS_introduce_baseset_auth-user-do:

実行手順
===================================================

|FMS| 管理者アカウントでポータル画面にログインし、 権限グループとユーザの関連づけを行います。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      システム管理
        権限グループ
          権限グループ管理

1. 「F6：検索」を押下し、権限グループ一覧を取得します。
2. 設定対象とする権限グループを選択し、「ユーザ」を押下します。
3. ユーザコードを指定し、「F5:新規」で当該権限グループへユーザを登録します。
  
  必要ユーザだけ、この手順を繰り返します。

4. 対象とする権限グループすべてについて、1.～3.の手順を実施します。

.. note::

  一括登録の場合、シート「マスタ設定シート_ユーザ権限グループ所属.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備し、同メニューの「SF5:一括登録」より登録します。

|FMS| にて支払や入金など会計処理を伴う取引の相手方となる社員の設定
-------------------------------------------------------------------------------

|FMS| にて支払や入金など会計処理を伴う取引の相手方となる社員として設定するには、
権限「社員資格権限」を含む権限グループに当該ユーザを所属させてください。

.. note::

  従業員口座の設定は :ref:`FMS_introduce_module_pr-employee_bank_account` を参照してください。

.. _FMS_introduce_baseset_auth-user-endConditions:

完了条件
===================================================

確認対象の権限グループを選択し、「SF7:プルーフリスト出力」でプルーフリストを取得し、内容を確認します。
