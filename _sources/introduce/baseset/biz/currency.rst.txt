.. _FMS_introduce_baseset_biz-currency:

===================================================
通貨登録
===================================================

|FMS| の用いる会社単位の通貨情報を登録します。

.. _FMS_introduce_baseset_biz-currency-startConditions:

着手条件
===================================================

:ref:`FMS_introduce_baseset_auth` までの作業を終えていること。


.. _FMS_introduce_baseset_biz-currency-do:

実行手順
===================================================

|FMS| 管理者アカウントでポータル画面にログインし、以下の通貨関連マスタの登録を行います。

.. _FMS_introduce_baseset_biz-currency-do-entry:

通貨の登録
---------------------------------------------------

会社の用いる通貨コード、通貨名、通貨略称、通貨検索名を登録します。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      マスタ管理
        通貨
          通貨管理

.. note::

  一括登録の場合は、シート「マスタ設定シート_通貨.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備し、同メニュー「SF5:一括登録」よりcsvファイルをロードします。

.. _FMS_introduce_baseset_biz-currency-do-precisionType:

通貨精度区分の登録
---------------------------------------------------

通貨精度区分を登録します。

.. note:: 
  
  |FMS| で用いる通貨精度区分は「FMS_AMOUNT」としてください。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      マスタ管理
        通貨
          通貨精度区分管理

.. note::

  一括登録の場合は、シート「マスタ設定シート_通貨精度区分.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備し、同メニュー「SF5:一括登録」よりcsvファイルをロードします。

.. _FMS_introduce_baseset_biz-currency-do-precision:

通貨精度の登録
---------------------------------------------------

:ref:`FMS_introduce_baseset_biz-currency-do-precisionType` で登録した精度区分「FMS_AMOUNT」と :ref:`FMS_introduce_baseset_biz-currency-do-entry` で登録した通貨コードを指定し、金額の有効桁数、および小数点以下の桁数を登録します。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      マスタ管理
        通貨
          通貨精度管理

.. note::

  一括登録の場合は、シート「マスタ設定シート_通貨精度.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備し、同メニュー「SF5:一括登録」よりcsvファイルをロードします。

.. _FMS_introduce_baseset_biz-currency-do-conversion:

通貨換算コードの登録
---------------------------------------------------

TTB、TTS、社内レートといった種別を登録します。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      マスタ管理
        通貨
          通貨換算コード管理

.. note::

  一括登録の場合は、シート「マスタ設定シート_通貨換算コード.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備し、同メニュー「SF5:一括登録」よりcsvファイルをロードします。


.. _FMS_introduce_baseset_biz-currency-do-rate:

通貨換算レートの登録
---------------------------------------------------

登録するレート別に、 :ref:`FMS_introduce_baseset_biz-currency-do-conversion` で登録した通貨換算コード、ならびに :ref:`FMS_introduce_baseset_biz-currency-do-entry` で登録した通貨コードから基準通貨コードと変換通貨コード、換算レート、有効期間を登録します。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      マスタ管理
        通貨
          通貨換算レート管理

.. note::

  一括登録の場合は、シート「マスタ設定シート_通貨換算レート.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備し、同メニュー「SF5:一括登録」よりcsvファイルをロードします。

.. _FMS_introduce_baseset_biz-currency-endConditions:

完了条件
===================================================

各メニューからプルーフリストを取得し、登録結果を確認します。
