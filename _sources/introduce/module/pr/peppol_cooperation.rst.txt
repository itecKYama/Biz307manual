.. _FMS_introduce_module_pr-peppol-cooperation:

===================================================
Peppol連携の各種設定
===================================================

Peppol連携する請求データの生成に関する各種設定を行います。

  .. note::

    請求データをPeppol連携しない場合 、本作業は不要です。

.. _FMS_introduce_module_pr-peppol-cooperation-startConditions:

着手条件
===================================================

* :ref:`FMS_introduce_baseset_im_master-department` が完了していること。

* :ref:`FMS_introduce_module_pr-customer` が完了していること。

.. _FMS_introduce_module_pr-peppol-cooperation-do:

実行手順
===================================================

.. _FMS_introduce_module_pr-peppol-cooperation-do-parameters:

パラメータを設定する
---------------------------------------------------

|FMS_ADM| でポータル画面にログインし、以下のメニューよりPeppol連携データ出力のパラメータを設定します。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          基本設定管理
            パラメータ管理

.. list-table::
   :widths: 1, 3
   :header-rows: 1

   * - 項目
     - 説明
   * - 自社法人番号（Peppol連携）
     - 請求データに出力される自社の法人番号を設定します。
   * - Peppol連携データ出力方法
     - | Peppol連携データ作成画面で実行した際の請求データの出力方法を設定します。
       |  0:画面、1:所定のフォルダ
       | Peppol連携データ出力ジョブで実行する場合には、1:所定のフォルダ を設定します。
   * - Peppol連携データ出力先
     - | 「Peppol連携データ出力方法」が 1:所定のフォルダ の場合に設定します。
       | Peppol連携用ディレクトリとして パブリックストレージ [#public_storage]_ からの相対パスを設定します。

.. [#public_storage] パブリックストレージのパスについては、 |BAPF| の |COOKBOOK| `ストレージパスを確認する`_ を参照してください。

.. _FMS_introduce_module_pr-peppol-cooperation-do-customer:

請求先の取引先情報を設定する
---------------------------------------------------

|FMS_ADM| でポータル画面にログインし、以下のメニューより「取引先法人番号」と「請求手段」を登録します。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          業務マスタ
            取引先マスタ管理

.. list-table::
   :widths: 1, 1, 5
   :header-rows: 1

   * - 項目
     - 画面タブ
     - 利用目的
   * - 取引先法人番号
     - 会計情報
     - 請求データに出力する取引先の法人番号を設定します。
   * - 請求手段
     - 請求先
     - Peppol連携を行う場合、 1:電子データ を設定します。締日一括請求申請で利用します。

.. _FMS_introduce_module_pr-peppol-cooperation-do-department:

請求データ連携用組織情報を登録する
---------------------------------------------------

|FMS_ADM| でポータル画面にログインし、以下のメニューより :ref:`FMS_introduce_module_pr-peppol-cooperation-do-customer` に紐づく取引先管理組織の住所情報を登録します。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          業務マスタ
            請求データ連携用組織情報登録

.. note::

  一括取込マニュアルの「 :ref:`FMS_import_mst-corp_cstm-invoice_data_interface_department` 」を参考に取込ファイルを準備し、同メニューの「SF5:一括登録」より登録します。

.. _FMS_introduce_module_pr-peppol-cooperation-do-directory:

Peppol連携用ディレクトリを作成する
---------------------------------------------------

  .. note::

     :ref:`FMS_introduce_module_pr-peppol-cooperation-do-parameters` で Peppol連携データ出力先 を指定した場合に実施します。

  パブリックストレージにPeppol連携用ディレクトリを作成します。

  * ディレクトリ作成::

    {パブリックストレージ}/{Peppol連携データ出力先}

  * 作成例

    下記条件下の環境では、作成例の箇所にPeppol連携用ディレクトリを作成します。

    * 作成条件

      * ストレージルートとして「${resin.home}/storage-files」を設定
      * テナントIDに「default」を使用
      * :ref:`FMS_introduce_module_pr-peppol-cooperation-do-parameters` のPeppol連携データ出力先に「peppol_cooperation/csv」を設定

    * 作成ディレクトリ::

        ${RESIN_HOME}/storage-files/public/storage/default/peppol_cooperation/csv

.. _FMS_introduce_module_pr-peppol-cooperation-endConditions:

完了条件
===================================================

* パラメータ管理画面より設定結果を確認します。

* 取引先マスタ管理画面よりプルーフリストの出力 または 画面検索を行い、「請求手段」「取引先法人番号」が登録できていることを確認します。

* 請求データ連携用組織情報登録画面よりプルーフリストの出力を行い、登録できていることを確認します。

* Peppol連携用ディレクトリが作成されていることを確認します。
