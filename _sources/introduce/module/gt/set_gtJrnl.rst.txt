===================================================
グループ会社間取引仕訳設定マスタの設定
===================================================
グループ会社間取引連携において、債務会社側の担当者における債務登録時に科目の指定誤りを防ぐため、事前に保持する仕訳パターンを登録します。

.. _FMS_introduce_module_gt-set_gtJrnl-startConditions:

着手条件
===================================================
:ref:`FMS_introduce_module_gt-jrnlptn` までの作業を終えていること。

.. _FMS_introduce_module_gt-set_gtJrnl-do:

実行手順
===================================================
Biz∫会計管理者アカウントでポータル画面にログインし、以下のメニューより、一括取込マニュアルの :ref:`FMS_import_mst-gt_gtJrnl-gt_gtJrnl` を参考に取込ファイルを準備し、同メニューの「SF5:一括登録」より登録します。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          業務マスタ
            グループ会社間取引仕訳設定マスタ登録
            
.. _FMS_introduce_module_gt-set_gtJrnl-endConditions:

完了条件
===================================================
* プルーフリスト出力を行い、登録した情報が登録されていることを確認します。
