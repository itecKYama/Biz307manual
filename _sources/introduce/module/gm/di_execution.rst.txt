.. _FMS_introduce_module_gm-di_execution:

===================================================
データ連携の実行
===================================================

|GM| を利用するために、既存のマスタ および トランザクションをテナントシェアードスキーマに連携します。

.. _FMS_introduce_module_gm-di_execution-startConditions:

着手条件
===================================================
:ref:`FMS_introduce_module_gm-di_job` までの作業を終えていること。

.. _FMS_introduce_module_gm-di_execution-do:

実行手順
===================================================

.. _FMS_introduce_module_gm-di_execution-do-job:

|DI| のジョブの実行、または、データ連携ワークロードの実行
-----------------------------------------------------------

:ref:`FMS_introduce_module_gm-di_job` で登録したジョブを実行、または、 :ref:`FMS_introduce_module_gm-di_wl_master` で登録したワークロードを実行し、既存データを連携します。

.. note::
  
  初回実行時は「全件連携」となるため、時間がかかる可能性があります。

**intra-martジョブネット管理から起動する場合**

  :ref:`FMS_cookbook_introduce_batch-job-run` を参照してください。

**コマンドラインから起動する場合**

  :ref:`FMS_cookbook_introduce_batch_gt-di_job` を参照してください。

**ワークロードを実行する場合**

 以下のメニューから該当のワークロードを実行してください。

* メニュー ::

    Biz∫ APF データ連携
      ワークロード実行管理
        ワークロード実行

.. _FMS_introduce_module_gm-di_execution-do-wkld:

月次状況（差分更新）連携ワークロードの実行
---------------------------------------------------

.. note::
  
  月次処理（月次確定/確定取消/仮実行）を実施した際には、前回の月次処理時点から更新された月次状況のみを連携します。

  運用開始前に当該ワークロードを実行しておくことで、初回の月次処理では本作業実施時点からの差分のみを連携することになります。

:ref:`FMS_introduce_module_gm-di_wl_master` で登録した 月次確定/確定取消/仮実行を実施した際に「月次状況」を連携するワークロード を実行します。

* メニュー ::

    Biz∫ APF データ連携
      ワークロード実行管理
        ワークロード実行

完了条件
===================================================
* グループ会社間取引照合画面で検索 または ファイル出力を行い、既存データが連携されていることを確認します。
* グループ会社法人別科目残高照会画面でファイル出力を行い、既存データが連携されていることを確認します。
* グループ会社月次状況照会画面で検索を行い、既存データが連携されていることを確認します。
