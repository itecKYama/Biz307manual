===================================================
プロジェクト登録
===================================================
プロジェクト原価管理で利用するプロジェクトを登録します。

.. note::

  プロジェクトを登録すると、自動的に分析コードやフィールド関連に反映され、仕訳登録や取引登録で利用可能となります。

.. _FMS_introduce_module_jc-project-startConditions:

着手条件
===================================================

:ref:`FMS_introduce_module_jc-contract_class` までの作業を終えていること。

.. _FMS_introduce_module_jc-project-do:

実行手順
===================================================
1.ワークフローの無効化
  |FMS_ADM| アカウントでポータル画面にログインし、ワークフローの承認を「無効」とします。

  * メニュー ::

      Biz∫ 会計
        会計コア
          マスタメンテナンス
            基本設定管理
              ワークフローパラメータ管理

  * 対象のワークフロー

    * 対象モジュール

      プロジェクト原価管理

    * ワークフローパラメータ名

      * プロジェクト開設

      * プロジェクト変更

2.プロジェクトを登録します。（画面登録の場合）
  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「F5:開設」を押下し、プロジェクトを登録します。

  * メニュー ::

     Biz∫ 会計
        プロジェクト原価管理
          申請書
            プロジェクト開設・変更

3.プロジェクトを登録します。（一括取込の場合）
  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「F5:実行」を押下し、プロジェクトを登録します。

  * メニュー ::

     Biz∫ 会計
        プロジェクト原価管理
          申請書
            プロジェクト一括取込

  .. note::

    一括登録を行う場合、一括取込マニュアルの :ref:`FMS_import_mst-project-project` を参考に取込ファイルを準備し、同メニューの「F5:実行」ボタンより登録します。

4.ワークフローの再設定
  |FMS_ADM| アカウントでポータル画面にログインし、プロジェクト登録のために無効にしておいたワークフローについて、承認の必要なものを「有効」にして下さい。

  * メニュー ::

     Biz∫ 会計
        マスタメンテナンス
          基本設定管理
            ワークフローパラメータ管理

  * 対象のワークフロー

    * 対象モジュール

      プロジェクト原価管理

    * ワークフローパラメータ名

      * プロジェクト開設

      * プロジェクト変更

.. _FMS_introduce_module_jc-project-endConditions:

完了条件
===================================================
* 一括登録を行った場合には、以下のメニューより「プロジェクト一括登録」がエラーなく終了していることを確認します。

  * メニュー ::

      Biz∫ APF アドミニストレーション 
        システム管理（会社共通）
          非同期タスク
            非同期タスクモニタ

* |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「SF7:プルーフリスト出力」を押下し、プロジェクトマスタコードのプルーフリストを出力し、登録内容が正しいことを確認します。

  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          申請書
            プロジェクト開設・変更

* |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「SF7:プルーフリスト出力」を押下し、プロジェクトサブコードのプルーフリストを出力し、登録内容が正しいことを確認します。

  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          申請書
            プロジェクト分割
