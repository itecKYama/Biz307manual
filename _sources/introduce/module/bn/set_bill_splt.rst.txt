===================================================
手形分割マスタの設定
===================================================
支払手形依頼処理では、手形分割マスタの設定値をもとに、手形を振り出す際の印紙税経済分割を行います。

手形分割マスタはインストール手順においてプリセットで登録されていますが、分割方法を変更したい場合には、本章の手順を実施します。

.. note::

  変更不要な場合には、本章を実施する必要はありません。

.. _FMS_introduce_module_bn-set_bill_splt-startConditions:

着手条件
===================================================
初期データの分割方法から変更が必要である場合。

.. _FMS_introduce_module_bn-set_bill_splt-do:

実行手順
===================================================

Biz∫会計管理者アカウントでポータル画面にログインし、以下のメニューより手形の分割方法に対して設定値を変更します。

    * メニュー ::
        
        Biz∫ 会計
          会計コア
            マスタメンテナンス
              業務マスタ
                手形分割登録

    1. 現状の確認

        プルーフリスト出力から手形分割マスタのデータを出力します。

        手形分割マスタのプリセットデータは、範囲内の金額につき最小の枚数を振り出す設定となっています。

        * 手形分割マスタのプリセットデータを一部抜粋

        .. figure:: ./images/set_bill_splt_001.png
            :width: 500px

    2. 手形分割マスタの更新

        一括取込マニュアルの :ref:`FMS_import_mst-bill_splt-bill_splt` の項目説明を参照し、必要に応じてプルーフリストの編集を行い、一括登録により、手形分割マスタのすべてのデータを洗い替えします。

        .. _FMS_introduce_module_bn-set_bill_splt-endConditions:

完了条件
===================================================
* 同メニューからプルーフリストを取得し、登録内容を確認します。

* 各項目の値が仕様と整合していることを確認します。

* 一括登録は非同期タスクとして実行されます。以下のメニューより「手形分割一括登録」がエラーなく終了していることを確認します。 ::
