===================================================
入力制限／月次更新対象外設定
===================================================

各モジュールの入力制限実行と月次更新実行に関する設定は、会計モジュールにプリセットで登録されています。

入力制限実行と月次更新実行について、利用しないモジュールを対象外とする場合に設定値を変更します。

* 入力制限実行

    * メニュー ::
        
        Biz∫ 会計
          会計コア
            更新処理
              入力制限実行

* 月次更新実行

    * メニュー ::
        
        Biz∫ 会計
          会計コア
            更新処理
              月次更新実行

.. _FMS_introduce_core-finance_module-do:

実行手順
===================================================

会計モジュール管理から、利用しないモジュールに対して設定値を変更します。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          基本設定管理
            会計モジュール管理


1. 利用しないモジュールを選択します。

2. 以下を'対象外'に変更します。

    * 入力制限実行フラグ
    * 月次更新実行フラグ

.. _FMS_introduce_core-finance_module-endConditions:

完了条件
===================================================
同画面から、選択したモジュールの入力制限実行フラグと月次更新実行フラグが対象外となっていることを確認します。
