.. _FMS_introduce_core-accounting_type:

===================================================
会計種別設定
===================================================
|FMS| が用いる取引区分や決算種別、 |BIZ| の他アプリケーション名称などを設定します。

.. _FMS_introduce_core-accounting_type-startConditions:

着手条件
===================================================
:ref:`FMS_introduce_core-parameter` を終えていること。

.. _FMS_introduce_core-accounting_type-do:

実行手順
===================================================
会計種別管理では、伝票の選択項目となる各種区分の選択肢を管理しています。

* 取引区分（現金、振込などFBの種別）

* 決算種別（決算仕訳・遡及仕訳の種別）

* アプリケーション区分（ |FMS| 以外の |BIZ_APP| の種別）

  .. note::
    建設仮勘定モジュールまたはプロジェクト原価管理モジュールを導入する場合は初期データで登録される「GK：会計」を非活動にしないで下さい。（詳しくは :ref:`FMS_introduce_module_jc-accounting_type` 参照）

* アプリケーション分類（ |BIZ| 以外のアプリケーションの種別。外部システムから伝票を取り込む予定がある場合に設定する）

  .. note::

    手形管理モジュールを導入する場合は初期データで登録される「bn：手形管理」を非活動にしないで下さい。（詳しくは :ref:`FMS_introduce_module_bn-accounting_type` 参照）

  .. note::
    電子記録債権管理モジュールを導入する場合は初期データで登録される「ec：電子記録債権管理」を非活動にしないで下さい。（詳しくは :ref:`FMS_introduce_module_ec-accounting_type` 参照）

  .. note::
    プロジェクト原価管理モジュールを導入する場合は初期データで登録される「11：固定資産移動」から「63：給与」を非活動にしないで下さい。（詳しくは :ref:`FMS_introduce_module_jc-accounting_type` 参照）

  .. note::
    建設仮勘定モジュールを導入する場合は初期データで登録される「71：建設仮勘定振替」を非活動にしないで下さい。（詳しくは :ref:`FMS_introduce_module_cp-accounting_type` 参照）

* 対象情報区分（予算の種別）

* 支払調書提出範囲グループ（債務管理で使用する支払調書提出範囲の分類）

* 源泉種類（債務管理で使用する源泉税の分類）

  .. note::
    本会計種別は :ref:`FMS_introduce_module_pr-tax_withholding_kind` で詳しく解説します。

* 取引詳細コード（資産管理で使用する取引詳細コード）

  .. note::
    本会計種別は :ref:`FMS_introduce_module_fa-accounting_type` で詳しく解説します。

* 経費コード（資産管理で使用する経費コード）

  .. note::
    本会計種別は :ref:`FMS_introduce_module_fa-accounting_type` で詳しく解説します。

* 分析ラベル名（資産管理の帳票に出力する分析フィールドのラベル名）

  .. note::
    本会計種別は :ref:`FMS_introduce_module_fa-accounting_type` で詳しく解説します。

* リース契約経費コード（リース契約管理で使用する経費コード）

  .. note::
    本会計種別は :ref:`FMS_introduce_module_lc-accounting_type` で詳しく解説します。

種別はプリセットで登録されています。

以上の種別と選択肢について、必要に応じてBiz∫会計管理者アカウントでポータル画面にログインし、以下のメニューより選択肢の追加・非活動化・名称変更を行います。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          基本設定管理
            種別管理

.. note::

  種別明細を追加する場合は、先頭が大文字となるコードを定義してください。（先頭が大文字でないコードはパッケージ標準で予約されています）

.. _FMS_introduce_core-accounting_type-endConditions:

完了条件
===================================================
同メニューより、追加した種別明細が検索できること、検索した種別明細の名称が変更されていることを確認します。
