.. _FMS_introduce_core-external_allocation_base_import:

===================================================
外部配賦基準登録
===================================================
設備稼働実績や人員比などの変動のある数値や、実績原価など |FMS| 外で算出した数値を用いて配賦する場合の基準を登録します。

.. _FMS_introduce_core-external_allocation_base_import-startConditions:

着手条件
===================================================
:ref:`FMS_introduce_core-account` 、 :ref:`FMS_introduce_baseset_im_master-department` を終えていること。

.. _FMS_introduce_core-external_allocation_base_import-do:

実行手順
===================================================
Biz∫会計管理者アカウントでポータル画面にログインし、以下のメニューより、一括取込マニュアルの :ref:`FMS_import_mst-allocate-ex_allocate` を参考に取込ファイルを準備し、同メニューの「SF5:一括登録」より登録します。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          業務マスタ
            外部配賦基準取込

.. _FMS_introduce_core-external_allocation_base_import-endConditions:

完了条件
===================================================
一括登録は非同期タスクとして実行されます。以下のメニューより「外部配賦基準取込」がエラーなく終了していることを確認します。 ::

    Biz∫ APF アドミニストレーション 
      システム管理（会社共通）
        非同期タスク
          非同期タスクモニタ
