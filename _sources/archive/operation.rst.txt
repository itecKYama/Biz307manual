.. _FMS_archive-operation-tenant_export:

テナントエクスポートを実行する
===================================================
テナントエクスポートを実行します。

#. アーカイブ元テナントに、Biz∫管理者権限をもつユーザーでログインします。

#. 「 |BAPF| 移送管理」→「テナントエクスポート」をクリックします。

#. 「ファイルを選択してください」をクリックし、 :ref:`FMS_archive-profile` をアップロードします。


#. 「エクスポート」ボタンをクリックします。

.. _FMS_archive-operation-tenant_import:

テナントインポートを実行する
===================================================
テナントインポートを実行します。

.. warning::

  初めてアーカイブする環境へのテナントインポートでは、インポート方式「削除して追加」を指定してください。

  過去にアーカイブした環境へのテナントインポートでは、インポート方式「マージ」を指定してください。

  **誤ってインポート方式「削除して追加」を指定した場合、ファイル管理テーブルがアーカイブ元と同じ内容になるため、過去にアーカイブ対象となった仕訳・取引の添付ファイルが確認できなくなります。**

#. アーカイブテナントに、Biz∫管理者権限を持つユーザーでログインします。

#. 「 |BAPF| 移送管理」→「テナントインポート」をクリックします。

#. 「ファイルを選択してください」をクリックし、 :ref:`FMS_archive-operation-tenant_export` で取得したデータをアップロードします。

#. 「インポート」ボタンをクリックします。

.. _FMS_archive-operation-fms_account_view:

科目ビューの更新
===================================================
.. note::

  本項は PostgreSQL を利用する場合の対応となります。

1. テナント管理者でログインし、以下のメニューを選択します。

  * メニュー ::

      テナント管理
        データベース操作

2. 以下のSQLを実行します。

::

  REFRESH MATERIALIZED VIEW fms_fc_v_account;

.. _FMS_archive-operation-file_copy:

仕訳・取引の添付ファイルフォルダをコピーする
===================================================
アーカイブした仕訳・取引の添付ファイルを確認できるよう、アーカイブテナントに添付ファイルフォルダをコピーします。

* 仕訳の添付ファイル

  .. code-block:: none
     :caption: アーカイブ元テナントのストレージ

     {ストレージルート}\public\storage\{アーカイブ元テナントID}\biz-integral\fms\{会社コード}\attachedFile\gl\journalEntry

  .. code-block:: none
     :caption: アーカイブ先テナントのストレージ

     {ストレージルート}\public\storage\{アーカイブ先テナントID}\biz-integral\fms\{会社コード}\attachedFile\gl\journalEntry

* 取引の添付ファイル

  .. code-block:: none
     :caption: アーカイブ元テナントのストレージ

     {ストレージルート}\public\storage\{アーカイブ元テナントID}\biz-integral\fms\{会社コード}\attachedFile\pr\dealEntry

  .. code-block:: none
     :caption: アーカイブ先テナントのストレージ

     {ストレージルート}\public\storage\{アーカイブ先テナントID}\biz-integral\fms\{会社コード}\attachedFile\pr\dealEntry
