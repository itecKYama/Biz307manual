===================================================
台帳系の組織の変更
===================================================
組織コードを項目として保持している台帳について、その項目に新しい組織を設定します。

.. _FMS_deptchg_set-hstry-startConditions:

着手条件
===================================================
:ref:`FMS_deptchg_preparation-shiftlist` の作業が完了していること。

新しい組織を追加する場合、 :ref:`FMS_deptchg_set-add` の作業が完了していること。

組織変更日以前の処理（例：経過勘定台帳における経過勘定振替処理）が実行されていること。

  .. note::

    フィールド関連マスタの非活動について

    　仕訳を作成する処理においてフィールド関連のエラーを発生させないため、計上組織を主フィールドまたは関連フィールドにもつフィールド関連（例：計上組織－プロジェクト）を非活動にしてください。プロジェクト原価管理にてフィールド関連を自動作成している場合、変更後の情報をもとにフィールド関連が自動作成されます。そのため、組織残高の振替仕訳の作成時に、変更前の組織でプロジェクトの計上ができなくなる可能性があります。上記を防止するために、計上組織を主フィールドまたは関連フィールドにもつフィールド関連（例：計上組織－プロジェクト）を非活動にしてください。

    　 :ref:`FMS_deptchg_set-balanceshift` 後、フィールド関連を活動中に戻してください。

.. _FMS_deptchg_set-hstry-do:

実行手順
===================================================
組織コードを項目として持つ台帳については、台帳の修正機能を使用して組織コードの修正を行います。画面から変更するほかに、組織変更モジュールの組織変更実行機能で変換することも可能です。

.. _FMS_deptchg_set-hstry-do-auto:

組織変更機能を使用して行う場合
---------------------------------------------------

組織変更実行機能を使用することにより以下の台帳に設定された組織を一括変換することができます。

.. list-table::
   :widths: 8, 5, 25, 20
   :header-rows: 1

   * - 対象台帳
     - 項目名
     - 前提条件
     - 更新対象
   * - 経過勘定台帳
     - 計上組織
     - * 組織変更日が属する月の前月の経過勘定振替処理が行われていること。
       * 経過勘定振替計上にて仮実行中でないこと。
       * 経過勘定振替計上で作成された仕訳で未承認状態のものがないこと。また作成された仕訳に対して、未承認状態の赤仕訳がないこと。
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの
   * - 手形台帳
     - 計上組織

       管理組織

     - * 手形台帳が承認中でないこと
       * 組織変更日より後の日付で手形履歴が存在しないこと。
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの
       * 手形状態区分が売却、破棄、決済以外の手形台帳
   * - 電子記録債権台帳
     - 計上組織

       管理組織

     - * 電子記録債権台帳が承認中でないこと
       * 組織変更日より後の日付で電子記録債権履歴が存在しないこと。
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの
       * 電子記録債権状態区分が売却、破棄、決済以外の電子記録債権台帳
   * - 固定資産台帳
     - 管理組織

       費用負担組織

     - * 組織変更日を含む月の前月の償却計算確定後に行うこと
       * 固定資産に対する取引が再申請待でない、または、承認中でないこと
     - * 組織コード変更情報に登録されている変更前組織と管理組織、または、費用負担組織が一致するもの
       * 組織変更日の翌日以降に資産取引を行っていないもの
   * - 建設仮勘定明細
     - 計上組織
     - * 組織変更日を含む月の前月の建設仮勘定振替登録処理がすべて完了後に行うこと
       * 建設仮勘定明細に対する取引が再申請待でない、または、承認中でないこと
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの
       * 未振替であるもの
   * - 契約台帳
     - 契約組織

       決済組織

       損益組織

     - * 組織変更日を含む月の前月の契約決算更新が必要な場合、契約決算更新終了後に行うこと
       * 契約に対する取引が再申請待でない、または、承認中でないこと
     - * 組織コード変更情報に登録されている変更前組織と以下のいずれかの組織が一致するもの

         契約組織、決済組織、損益組織
       * 契約中であるもの
   * - プロジェクト
     - 管理組織
     - * 組織変更日を含む月の前月の月次処理が終了していること
       * プロジェクト申請がが再申請待でない、または、承認中でないこと
     - * 組織コード変更情報に登録されている変更前組織と管理組織が一致するもの
       * 組織変更日に有効なもの
   * - 工事台帳
     - 管理組織
     - * 組織変更日を含む月の前月の月次処理が終了していること
       * プロジェクト申請が再申請待でないこと、または、承認中でないこと
     - * 組織コード変更情報に登録されている変更前組織と管理組織が一致するもの
       * 組織変更日時点で未完成のもの。
       * 組織変更年度の場合、ステータスが"原価差額"でないこと
   * - 稼働実績
     - 計上組織
     - * 組織変更日を含む月の前月の月次処理が終了していること
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの
       * 組織変更日の前月以前に計上されているもの


注意事項を以下に示します。

.. list-table::
   :widths: 8, 45
   :header-rows: 1

   * - 対象台帳
     - 注意事項
   * - 手形台帳
     - 組織変更日より後の日付で手形履歴が存在した場合、受取手形登録/支払手形登録画面から、処理日を最後の手形履歴の処理日以降の日付とし、計上組織/管理組織の変更を行ってください。
   * - 電子記録債権台帳
     - 組織変更日より後の日付で電子記録債権履歴が存在した場合、電子債権登録/電子債務登録登録画面から、処理日を最後の電子記録債権履歴の処理日以降の日付とし、計上組織/管理組織の変更を行ってください。
   * - 固定資産台帳
     - 組織変更日より後の日付で資産履歴が存在した場合、資産組織変更画面あるいは資産移動画面から、処理日を最後の資産履歴の処理日以降の日付とし、管理組織/費用負担組織の変更を行ってください。

       組織変更に係る移動の仕訳が作成されます。（資産管理パラメータ.移動の会計連携:1(有)の場合）

   * - 建設仮勘定
     - 建設仮勘定の組織振替の仕訳が作成されます。
   * - 契約台帳
     - 組織変更日より後の日付で契約履歴が存在した場合、契約変更画面から、処理日を最後の契約履歴の処理日以降の日付とし、契約組織/決済組織/損益組織の変更を行ってください。

       組織変更に係るリース債務残高振替の仕訳が作成されます。（リース契約管理パラメータ.契約変更仕訳インタフェース:1(仕訳IFを行う)の場合）

   * - プロジェクト
     - 組織変更日の前月の月次処理で原価差額配賦が実行されている場合、管理組織が変更されると、原価差額配賦戻しの仕訳が作成されます。

       そのため、前月の月次処理で原価差額配賦仕訳が計上されているプロジェクトは、組織変更日時点で有効となるように有効期間の変更が必要になります。
   * - 工事台帳
     - 変更前組織から変更後組織への残高振替の仕訳が作成されます。組織別経理簿等で「分割等」に集計されます。
   * - 稼働実績
     - 稼働実績が変更前組織から変更後組織に付け替えられます。そのため、組織変更日以降の月次処理において、原価差額が変更後組織に対して配賦されます。

===================================================

      システム管理(会社共通)
        非同期タスク
          非同期タスクモニタ
