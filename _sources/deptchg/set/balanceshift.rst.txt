===================================================
残高の移行
===================================================
組織変更日から組織が変更となる場合、組織変更日にその組織の残高を組織変更後の組織に移行します。

推奨する運用手順は以下の通りです。

1. 組織残高振替仕訳を仮仕訳で作成する。

2. 仮仕訳を含めて試算表を出力して確認する。

3. 本仕訳登録する

.. _FMS_deptchg_set-balanceshift-startConditions:

着手条件
===================================================
:ref:`FMS_deptchg_preparation-shiftlist` の作業が完了していること。

新しい組織を追加する場合、 :ref:`FMS_deptchg_set-add` の作業が完了していること。

.. _FMS_deptchg_set-balanceshift-do:

実行手順
===================================================
移行を実施する前に、組織変更日時点の試算表を出力し保存してください。移行後の確認で使用します。

.. _FMS_deptchg_set-balanceshift-do-auto:

組織変更機能を使用して行う場合
---------------------------------------------------
組織変更実行機能を使用することにより残高を振り替えた仕訳を作成することができます。

.. _FMS_deptchg_set-balanceshift-do-auto-sup:

組織変更実行機能を使用する場合の説明
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
組織変更実行機能を使用して残高を移行した場合、取得元や作成される残高振替仕訳は以下の通りとなります。

1. 振替対象となる残高の取得元

  以下の条件を全て満たす残高が振替対象となります。

  * 組織変更日が属する月の前月末の分析フィールド別元帳残高＋計上日が組織変更日の組織変更実行にて作成された仕訳(承認済のみ)
  * 科目残高繰越フラグが繰越対象の科目残高（繰越対象外の科目を調整する必要がある場合は、一般会計のメニュー「仕訳登録」「仕訳一括取込」、または組織変更のメニュー「組織残高振替仕訳作成」「組織残高振替仕訳一括取込」から調整仕訳を登録してください）
  * 仕訳種類が通常または決算（ただし決算種別が遡及のものを除く）
  * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの

2. 作成される仕訳の単位

  * 組織/科目単位で1仕訳作成します。ただし、パラメータ.組織残高振替仕訳作成明細行上限に設定された明細数を超えた場合、2仕訳目が作成されます。
  * 分析フィールド別元帳残高の単位を1仕訳明細として振替を行います。そのため、補助科目が多数ある場合や分析コードを多数使用している場合、1仕訳内の明細数が増加します。

3. 作成される仕訳の仕訳種類

  組織変更日が所属する年度の前年度分・・・・決算仕訳分も通常仕訳に集約し作成されます。

  組織変更日が所属する年度分・・・・・・・・分析フィールド別元帳残高の仕訳種類で作成されます。

4. その他

  * 組織残高振替仕訳作成を複数回実行した場合、その時点で存在する組織残高振替仕訳の仮仕訳は一括で削除されます。(洗い替え)
  * 組織残高振替仕訳作成では、仕訳作成処理前に以下のチェックを行い、エラーがある場合は、仕訳を作成しません。（1仕訳も作成しない）

    1. 組織・・・組織コード変更情報に登録されている組織コードが組織変更日時点で組織マスタに存在し、かつ組織が所属する本支店組織グループはひとつであること

    2. 権限・・・組織変更作業者に対して全起票組織伝票更新権限が付与されていること、変更前および変更後組織の所属する組織グループに紐づいた会計計上組織伝票更新権限が付与されていること

    3. 日付・・・組織変更日が属する月がオープンしていること、入力制限がかかっていないこと

      .. note::

        科目/補助については、組織変更日時点で有効なもののみ振替対象とします。

    .. note::

      上記のチェックでエラーとならない場合、仮仕訳が作成されます。しかし以下のエラーが発生している場合がありますので、必ず組織変更処理結果リストを確認し、エラーとなっている仮仕訳がある場合は組織残高振替仕訳登録画面より修正してください。

      1. フィールド関連のエラー(変更前の組織では使用できた分析コードが変更後の組織では使用できない等)

      2. 取引先、社員、分析コードの有効期間切れ

  * 組織残高振替仕訳作成で仕訳を登録すると、本支店仕訳明細は作成されません。本支店仕訳明細を作成する必要がある場合は、一般会計のメニュー「仕訳登録」「仕訳一括取込」から振替仕訳を登録してください。
  * 振替対象となる科目の条件は「科目残高繰越フラグが繰越対象」であるため、損益計算書・製造原価報告書の対象となる科目は振替対象になりません。そのため、期中に本支店を跨った組織変更を組織変更実行画面を使用して行い、本支店別の貸借対照表・損益計算書・製造原価報告書の利益額を一致させる必要がある場合は、損益計算書・製造原価報告書の対象科目の振替を行ってください。

.. _FMS_deptchg_set-balanceshift-do-auto-do:

組織変更実行機能を使用する場合の実行手順
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

1. :ref:`FMS_import_mst-department-dept_upd` を参考にcsvファイルを準備し、以下のメニューの「SF5:一括登録」より登録します。

  .. note::

    既に登録済の場合は2.に進んでください。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            組織変更情報登録

2. 以下のメニューにて組織残高振替仕訳作成を選択し、「F5:実行」で未消込残高振替仕訳を自動作成します。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            組織変更実行

3. 以下のメニューにて対象のタスクを検索し、結果に添付されている組織変更処理結果リストで実行結果を確認してください。

  * メニュー ::

      システム管理(会社共通)
        非同期タスク
          非同期タスクモニタ

4. 必要に応じて、台帳系の組織の変更を行ってください。

  .. note::

    * 台帳系の組織変更を画面または一括登録で行った場合仕訳が二重計上されます。その場合、組織残高振替仕訳を削除してください。

5. 組織残高振替仕訳は仮仕訳で作成されるため、試算表で移行結果が正しいことを確認後、以下のメニューにて「組織残高振替仕訳　本仕訳一括登録」を選択し、「F5:実行」で本仕訳に更新してください。

  .. note::

    * 処理対象となった仕訳に不備がある場合、「組織残高振替仕訳　仮仕訳一括削除」を選択して実行することにより組織残高振替にて作成された仮仕訳の一括削除も可能となっています。

    * 決算仕訳、仮仕訳で作成された組織残高振替仕訳を試算表等で確認する場合は、出力条件にて仕訳選択の決算から組織残高振替仕訳の決算種別を選択し、仕訳選択の仮仕訳から「残高振替」を選択して出力してください。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            組織変更実行

.. _FMS_deptchg_set-balanceshift-do-manual:

画面または一括登録で行う場合
---------------------------------------------------

1. 必要に応じて、台帳系の組織の変更を行ってください。


2. 以下のメニューより組織残高振替仕訳登録または組織残高振替仕訳一括登録にて組織残高振替仕訳を登録してください。

  .. note::

    * 仕訳種類は通常/決算のどちらでも作成できますが、決算仕訳で行う場合は、組織移行のための決算種別を設定してから行ってください。また、該当年度の帳票出力時に組織変更用の決算仕訳を含める必要があります。

    * 台帳系の組織変更による仕訳の科目を除いた組織残高振替仕訳を作成してください。

  * 組織残高振替仕訳登録 ::

      Biz∫ 会計
        業務共通
          組織変更
            組織残高振替仕訳計上

  * 組織残高振替仕訳一括登録 ::

      Biz∫ 会計
        業務共通
          組織変更
            組織残高振替仕訳一括取込

.. note::

  組織残高振替仕訳登録または組織残高振替仕訳一括登録から仕訳を登録すると、本支店仕訳明細は作成されません。本支店仕訳明細を作成する必要がある場合は、一般会計のメニュー「仕訳登録」「仕訳一括取込」から振替仕訳を登録してください。

.. _FMS_deptchg_set-balanceshift-sup:

補足説明
===================================================

* 組織残高振替仕訳の本仕訳を更新/削除することはできません。

* 組織残高振替仕訳は一般会計の仕訳登録画面では参照できません。

.. _FMS_deptchg_set-balanceshift-endConditions:

完了条件
===================================================
新しい組織の組織変更日時点の試算表を出力してください。移行前に出力した試算表と突き合わせて、旧組織の残高が全て移行されていることを確認してください。

.. note::

   :ref:`FMS_deptchg_set-hstry` でフィールド関連を非活動にした場合、フィールド関連を活動中に戻してください。
