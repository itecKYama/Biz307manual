.. _FMS_deptchg_set-mst:

===================================================
組織に関わるマスタの変更
===================================================
組織コードを項目として保持しているマスタについて、その項目に新しい組織を設定します。

.. _FMS_deptchg_set-mst-startConditions:

着手条件
===================================================
:ref:`FMS_deptchg_preparation-shiftlist` の作業が完了していること。

新しい組織を追加する場合、 :ref:`FMS_deptchg_set-add` の作業が完了していること。

.. _FMS_deptchg_set-mst-do:

実行手順
===================================================
有効期間を持つマスタについては、組織変更日時点でマスタを分割し、組織変更日以降の期間のマスタを更新します。

以下に、対象となるマスタと手順を示します。一部のマスタは組織変更モジュールのマスタ一括変換機能で変換することも可能です。

.. _FMS_deptchg_set-mst-do-auto:

組織変更機能を使用して行う場合
---------------------------------------------------
マスタ一括変換実行機能を使用することによりマスタに設定された組織を一括変換することができます。

.. list-table::
   :widths: 7, 10, 10, 25, 10
   :header-rows: 1

   * - 対象マスタ
     - 項目名
     - 前提条件
     - 更新対象
     - 運用制限
   * - 仕訳パターン
     - 計上組織コード
     - 
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの。
       * 有効期間終了日が組織変更日以降のもの。
       * 有効期間が組織変更日を跨ぐものは期間分割されます。
     - 
   * - 取引先
     - 取引先管理組織コード
     - 更新対象の取引先が承認中でないこと。
     - * 組織コード変更情報に登録されている変更前組織と取引先管理組織が一致するもの。
       * 有効期間終了日が組織変更日以降のもの。
       * 有効期間が組織変更日を跨ぐものは期間分割されます。
     - 
   * - 社内口座
     - 組織コード
     - 
     - * 組織コード変更情報に登録されている変更前組織と計上組織が一致するもの
       * 有効期間終了日が組織変更日以降のもの。
       * 有効期間が組織変更日を跨ぐものは期間分割されます。
     - 

.. note::

  全てのマスタについて、削除フラグが非活動のマスタはマスタ一括変換の対象外です。
  プロジェクトの組織変更については、 :ref:`FMS_deptchg_set-hstry` で実施してください。

1. :ref:`FMS_import_mst-department-dept_upd` を参考にcsvファイルを準備し、以下のメニューの「SF5:一括登録」より登録します。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            組織変更情報登録

2. 以下のメニューにて変換を行うマスタを選択し、「F5:実行」でマスタの一括変換を行います。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            マスタ一括変換

.. _FMS_deptchg_set-mst-do-manual:

画面または一括登録で行う場合
---------------------------------------------------

.. list-table::
   :widths: 10, 10, 10, 10, 20
   :header-rows: 1

   * - 対象マスタ
     - 項目名
     - 導入マニュアル手順
     - 使用モジュール
     - 備考
   * - 仕訳パターン [#f1]_
     - 計上組織コード
     - :ref:`FMS_cookbook_introduce_pattern`
     - 全モジュール
     - 
   * - 取引先 [#f1]_
     - 取引先管理組織コード
     - :ref:`FMS_introduce_module_gl-customer_gl`

       :ref:`FMS_introduce_module_pr-customer`

     - 一般会計

       債権債務

     - 承認中の取引先を更新する場合は、承認してから更新してください。

   * - 社内口座 [#f1]_
     - 組織コード
     - :ref:`FMS_introduce_module_pr-company_bank_account`
     - 債権債務
     - 
   * - 契約者番号
     - 計上組織コード
     - :ref:`FMS_introduce_module_pr-contractor_no`
     - 債権債務
     - 関連する仕訳パターンで、計上組織コードを設定している場合は、仕訳パターンを含め修正してください。
   * - 配賦元先
     - 計上組織コード
     - :ref:`FMS_introduce_core-allocate`
     - 会計コア
     - 
   * - 外部配賦基準
     - 計上組織コード
     - :ref:`FMS_introduce_core-external_allocation_base_import`
     - 会計コア
     - 
   * - 予算
     - 計上組織コード
     - :ref:`FMS_introduce_module_ma-budget_import`

       :ref:`FMS_introduce_module_ma-budget_fix`

     - 管理会計
     - 予算は年単位に設定するため、組織変更日以降の年度の予算を登録し直してください。
   * - 権限グループ
     - 組織グループコード
     - :ref:`FMS_introduce_baseset_auth`
     - 全モジュール
     - 組織データアクセス制御で、ユーザが使用できる組織グループを設定しています。組織の変更により、修正する必要があれば設定を変更してください。

       なお、権限は **システム日付** で有効か無効かを判断するため、有効期間は組織変更日でなく、実際にその組織グループコードを使用する日付から有効にしてください。

   * - フィールド関連
     - 主フィールドマスタコード

       初期値コード

       入力制限対象関連フィールドマスタコード

     - :ref:`FMS_introduce_core-field_relation`
     - 一般会計債権債務
     - 以下の二つのフィールド関連を更新します。

       * 主フィールドに起票組織、もしくは計上が指定されたフィールド関連。

       * 関連フィールドに計上組織が設定されたフィールド関連。

       プロジェクト原価管理導入時、計上組織とプロジェクトのフィールド関連は自動的に変更後の情報に更新されます。

   * - 契約種別仕訳
     - 組織コード
     - :ref:`FMS_introduce_module_lc-contract_class_jrnl`
     - 契約管理・リース管理
     - 組織設定区分が“設定値”の場合に変更してください。

   * - 間接費組織グループ
     - 組織グループコード
     - :ref:`FMS_introduce_module_jc-overhead_deptgrp`
     - プロジェクト原価管理
     - 単金を設定する組織グループが追加された場合に変更してください。

       間接費組織グループを追加する場合、組織グループや組織グループ所属の有効期間開始日は期首日としてください。

   * - 単金
     - 原価差額計上組織コード
     - :ref:`FMS_introduce_module_jc-plan_amount`
     - プロジェクト原価管理
     - 以下の場合に変更してください。

       * 間接費組織グループが追加された場合

       * 原価差額計上組織が他の組織グループに所属する組織に移動した場合

.. rubric:: 脚注

.. [#f1] マスタ一括変換で実施済みの場合、対応不要

完了条件
===================================================
**組織変更機能を使用して行う場合**

  以下のメニューにて対象のタスクを検索し、結果に添付されている組織変更処理結果リストで実行結果を確認してください。

  * メニュー ::

      システム管理(会社共通)
        非同期タスク
          非同期タスクモニタ

**画面または一括登録で行う場合**

  導入マニュアルの各項の完了条件を確認してください。
