===================================================
残高の移行（未消込残高の移行）
===================================================
組織変更日までに消込されない旧組織で計上されている仕訳明細について、新組織で処理を可能とするために、付替えを行います。

.. note::

  未消込残高の振替は、入金支払予定日を考慮したタイミングで行ってください。例えば、組織変更日直後に新組織において振込で支払を行う必要がある場合、組織変更日前に振替を行う必要があります。

.. _FMS_deptchg_set-balanceshift_nrcncl-startConditions:

着手条件
===================================================
:ref:`FMS_deptchg_preparation-shiftlist` の作業が完了していること。

新しい組織を追加する場合、 :ref:`FMS_deptchg_set-add` の作業が完了していること。

.. _FMS_deptchg_set-balanceshift_nrcncl-do:

実行手順
===================================================
債権一覧表、債務一覧表、仮受金未消込一覧表、仮払金未消込一覧表、残高明細顛末照会から、旧組織で計上されている未消込の債権、債務、入金、支払依頼、振替の各仕訳明細を検索します。

以下の手順で旧組織の明細を消し込んで、新組織に付け替えます。

.. _FMS_deptchg_set-balanceshift_nrcncl-do-auto:

組織変更機能を使用して行う場合
---------------------------------------------------
組織変更実行機能を使用することにより仕訳種別単位に未消込残高を振り替えた仕訳を作成することができます。

.. _FMS_deptchg_set-balanceshift_nrcncl-do-auto-sup:

組織変更実行機能を使用する場合の説明
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
組織変更実行機能を使用して未消込残高振替仕訳を作成する場合、振替対象や前提条件は以下の通りとなります。

1. 振替対象

  * 元仕訳の計上日＜組織変更日のもの
  * 仕訳種別が債権/債務の場合、入金支払予定日≧組織変更日のもの
  * 組織コード変更情報に変更前組織として登録されている組織に計上されかつ消込残のある仕訳明細(一部消込済も対象になります)

2. 前提条件

  * 未消込の明細に対する承認中の消込仕訳が存在しないこと。
  * 元仕訳に対する承認中の赤仕訳が存在しないこと。
  * 債権の場合、消込依頼が登録されていないこと。

  .. note::

    上記のような仕訳明細が存在した場合は、組織変更処理結果リストにエラーとして出力します。

3. その他

  * 入金支払予定日が組織変更日より前の債権/債務については、振替対象になりません。

    組織変更日より前に入金支払予定日が到来していると、この入金支払予定日を変更せずに債権債務を振り替える仕訳を組織変更日に計上することはできないため、振替後の入金支払予定日を判断し、入金支払予定日を設定しなおして振り替える仕訳を画面から登録してください。
  * 未消込残高振替仕訳は仕訳種別が債権/債務で締日<組織変更日の場合、締日には組織変更日が設定されます。

    (例)　組織変更日　4/1　の場合

      締日　3/31　の仕訳・・・・・4/1を設定

      締日　4/5 　の仕訳・・・・・4/5を設定

  * 未消込残高振替仕訳は、元仕訳の仕訳種別のまま承認済で作成されます

    .. note::

      例：債権の仕訳明細が未消込だった場合、仕訳種別:債権、承認済で作成されます。

  * 設定誤りなどにより未消込残高振替仕訳を修正する必要がある場合、以下の手順で修正してください。

    1. 以下のメニューより、作成された未消込残高振替仕訳を検索して修正します。

      「債権計上」をチェックした場合 ::

        Biz∫ 会計
          債権管理
            債権管理
              債権検索

      「入金」をチェックした場合 ::

        Biz∫ 会計
          債権管理
            入金管理
              入金仕訳検索

      「債務計上」をチェックした場合 ::

        Biz∫ 会計
          債務管理
            債務管理
              債務検索

      「支払」をチェックした場合 ::

        Biz∫ 会計
          債務管理
            支払管理
              支払依頼検索

      「振替」をチェックした場合 ::

        Biz∫ 会計
          一般会計
            仕訳入力
              仕訳検索



.. _FMS_deptchg_set-balanceshift_nrcncl-do-auto-do:

組織変更実行機能を使用する場合の実行手順
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

1. :ref:`FMS_import_mst-department-dept_upd` を参考にcsvファイルを準備し、以下のメニューの「SF5:一括登録」より登録します。

  .. note::

    既に登録済の場合は2.に進んでください。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            組織変更情報登録

2. 以下のメニューにて未消込残高振替仕訳作成を選択し、「F5:実行」で未消込残高振替仕訳を自動作成します。

  .. note::

    未消込残高振替仕訳作成の対象となった仕訳明細のうち、エラーが発生しなかったものは、仕訳が作成されます。組織変更処理結果リストを参照してエラー内容を確認し、画面から振替を行ってください。また、エラー原因がマスタの不備だった場合は、マスタを修正後、再実行することも可能です。

  * メニュー ::

      Biz∫ 会計
        業務共通
          組織変更
            組織変更実行

.. _FMS_deptchg_set-balanceshift_nrcncl-do-manual:

---------------------------------------------------
