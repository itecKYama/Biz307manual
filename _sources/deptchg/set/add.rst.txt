.. _FMS_deptchg_set-add:

===================================================
組織の追加
===================================================
新しい組織を作成します。

.. _FMS_deptchg_set-add-startConditions:

着手条件
===================================================
組織の追加は、新規の組織コードを追加する場合に実施します。

.. _FMS_deptchg_set-add-preparation:

事前準備
===================================================
一括登録用の参考情報として現在の情報についてはテナント管理者でログインし、以下のメニューよりジョブネット「IM共通マスタ - エクスポート - 会社・組織(imm-jobnet-company-export)」にて取得できます。

* メニュー ::

    テナント管理
      ジョブ管理
        ジョブネット設定

.. note::

  手順については、intra-mart WebPlatform/AppFramework IM-共通マスタ インポート・エクスポート 仕様書の6章「インポート／エクスポートの実行」を参照してください。

.. _FMS_deptchg_set-add-do:

実行手順
===================================================
:ref:`FMS_introduce_baseset_im_master-department` の手順と :ref:`FMS_introduce_baseset_auth-dept_group` の手順を実施し、組織マスタと組織グループ所属マスタの登録を行ってください。

また、その際、組織と組織グループ所属の有効期間は、組織変更日時点から有効にしてください。

**一括登録で行う場合の注意事項**

1. 新規組織の有効期間開始日を組織変更日にして組織マスタに追加します。

   取込ファイルには新規組織のみ記入してください。

2. 会社内包マスタを追加します。

   取込ファイルは既存を含む全ての内包マスタの情報を記入してください。

   一括登録で会社内包マスタを登録する場合、全ての組織内包が期間分割されます。

.. note::

  1.のみ一括登録で行い、2.は画面から行う事も可能です。小規模な組織変更の場合、画面から行った方が簡単です。

.. _FMS_deptchg_set-add-endConditions:

完了条件
===================================================
登録した組織を組織登録画面から確認します。

登録した組織グループ所属を、組織グループ所属登録画面から確認します。
