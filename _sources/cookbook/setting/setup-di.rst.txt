.. _FMS_cookbook_setting_setup-di:

===================================================================
|DI| の設定をする
===================================================================

|DI| のマスタ設定 および データベース・リンク の作成を行います。

.. note::

  |DI| のマスタ登録画面の操作方法については、 |BAPF| のBiz∫データ連携モジュール `操作ガイド`_ を参照してください。

.. _FMS_cookbook_setting_setup-di-pre:

前提条件
===================================================

* |DI| のインストールが完了していること。

.. _FMS_cookbook_setting_setup-di-do:

実行手順
===================================================

.. _FMS_cookbook_setting_setup-di-do-database:

データベースを登録する
---------------------------------------------------

|DI| のタスクで利用するデータベースを登録します。

* メニュー ::

    Biz∫ APF データ連携
      マスタ管理
        データベース管理

* 設定内容

  .. note::

   テナントデータベース および シェアードデータベースを登録します。
   
   複数テナントに導入している場合、全てのテナントデータベースを登録してください。


  .. list-table::
     :widths: 5, 15
     :header-rows: 1

     * - 項目
       - 設定値
     * - データベースコード
       - ・テナントデータベース の場合
           テナントID
         
         ・シェアードデータベース の場合
           shared
           
     * - 接続ID
       - IM-Jugglingプロジェクト内の設定ファイル「data-source-mapping-config.xml」に指定した接続ID
         
         ・テナントデータベース の場合
           tenant-data-source/tenant-id に指定した値
         
         ・シェアードデータベース の場合
           shared-data-source/connect-id に指定した値

.. _FMS_cookbook_setting_setup-di-do-create-dblink:

データベース・リンクを作成する
---------------------------------------------------

テナントデータベースからシェアードデータベースへのアクセスにOracleデータベース・リンクを利用しない場合、本手順は不要です。

.. note::

  データベース・リンクを利用する場合、|DI| の「OracleJdbcLoaderサブスクライブタスク」のマスタにデータベース・リンクを設定します。
 
 
  複数テナントに導入している場合、全てのテナントユーザに対して実施してください。
 



1. 管理者ユーザでデータベースにログインします。

2. 次のSQLを実行し、テナントユーザに対してデータベース・リンクを作成する権限を付与します。ユーザ名は環境に合わせて変更してください。

  .. code-block:: none

    GRANT CREATE DATABASE LINK TO iap_tenant;

3. テナントユーザでデータベースにログインします。

4. 次のSQLを実行し、データベース・リンクを作成します。データベース・リンク名、ユーザ名、パスワード、ホスト、ポート番号、ServiceName名は環境に合わせて変更してください。

  .. code-block:: none

      CREATE DATABASE LINK dblink
      CONNECT TO iap_tenant_shared
      IDENTIFIED BY XXXXXXXX
      USING '(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=127.0.0.1)(PORT=1521))(CONNECT_DATA=(SERVICE_NAME=orcl)))';

.. _FMS_cookbook_setting_setup-di-do-create-wkld:

科目マスタの取込ワークロードを実施する
---------------------------------------------------

.. note::

  本章はPostgreSQL を利用する場合の対応となります。
 
科目マスタの取込ワークロード(FMS.FC.ACCOUNT_SUB_WKLD_{テナントID}_{会社コード})のステップに科目ビューのリフレッシュタスクを追加します。

* メニュー ::

    Biz∫ APF データ連携
      マスタ管理
        ワークロード管理

* 設定内容

  .. list-table::
     :widths: 5, 15
     :header-rows: 1

     * - 項目
       - 設定値
     * - 実行順
       - 既存ステップの実行順の最大値+1
     * - タスクコード
       - FMS.FC.V_ACCOUNT_DML_POSTGRE_{テナントID}
     * - ステップ名
       - 任意
