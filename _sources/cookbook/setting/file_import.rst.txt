================================================================
ジョブ実行における取込ファイルを配備するディレクトリを作成する
================================================================

ジョブを利用したファイル取込において、取込するファイルを配備するディレクトリを作成します。

実行手順
===================================================

1. パブリックストレージのパスを確認

  |BAPF| の |COOKBOOK| `ストレージパスを確認する`_ を参照してください。


2. ディレクトリの作成

  以下のとおり、 |BAPF| の共有ストレージサービスで利用するディレクトリ内に、fileImportディレクトリおよび機能名ディレクトリを作成します。
  
  .. note::
  
    本作業は、ジョブでの取込を行う会社ごとに行います。
  
  * ディレクトリ作成::
  
    {1.で確認したパブリックストレージ}/biz-integral/fms/{会社コード}/upload/{モジュール}/fileImport/{機能名}

    各ジョブのモジュールおよび機能名は以下となります。

    .. list-table::
       :widths: 15, 5, 10
       :header-rows: 1

       * - 対象ジョブ
         - モジュール
         - 機能名
       * - 振込入金一括取込ジョブ
         - pr
         - transferIncomeImport
       * - 口座振替結果ファイル取込ジョブ
         - pr
         - bkAccTransResultImport
       * - 自動引落取込ジョブ
         - pr
         - autoDebitImport

  * 作成例
  
    下記の作成条件では、以下のようなディレクトリを作成します。
    
    * 作成条件
    
      * ストレージルートに「${resin.home}/storage-files」を設定
      * テナントIDに「default」を使用
      * 会社コードにサンプル会社「BZ1」を使用
      * 対象ジョブは「振込入金一括取込ジョブ」を使用

    * 作成ディレクトリ::
    
        ${RESIN_HOME}/storage-files/public/storage/default/biz-integral/fms/BZ1/upload/pr/fileImport/transferIncomeImport
