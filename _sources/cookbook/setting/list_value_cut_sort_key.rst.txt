.. _FMS_cookbook_setting_list_value_cut_sort_key:

============================================================
仕訳取引明細検索／仕訳明細検索のソートキーの選択肢を絞り込む
============================================================

会計コアの仕訳取引明細検索画面 および 一般会計の仕訳明細検索画面の検索結果の表示順を制御するソートキーコンボボックスのリスト値を絞り込みます。

| プリセットのままの場合、ソートキーコンボボックスのリストに会社コード、会社名を除くファイル出力の項目全てを表示します。
| 表示件数が多いため、不要なソートキーを非表示とし、リストに表示する件数を絞り込む場合に実施します。
| 表示内容の変更が不要な場合は本手順を実施する必要はありません。

.. note::

     パラメータ：「仕訳取引明細検索 債権債務出力項目非表示フラグ」の値により、ソートキーコンボボックスのリスト値が異なります。

     * 「0：表示」　：債権債務に関する項目を表示します。
     * 「1：非表示」：債権債務に関する項目を表示しません。

     ※一般会計の仕訳明細検索画面のリスト値は「1：非表示」に該当します。

.. _FMS_cookbook_setting_list_value_cut_sort_key-do:

実行手順
===================================================

会社コードの単位で設定が必要になります。会社コードの件数分、本手順を実行します。

.. _FMS_cookbook_setting_list_value_cut_sort_key-do-add:

コンボボックスに表示するリスト値の絞り込み（非表示にするリスト値のレコード追加）
--------------------------------------------------------------------------------


  | 直接のDB操作を必要とします。
  | 以下のレコードを追加します。（サーバの再起動は必要ありません）

  
  * 対象テーブル ::
  
      FMS_FC_LISTVALUE_CUT
  
  * 追加レコードの設定値
    
    以下の行を追加します。
    
    .. list-table::
       :widths: 3, 12
       :header-rows: 1

       * - 項目名
         - 設定値 [#f1]_
       * - company_cd
         - 対象の会社コード
       * - skip_cd
         - FC006_001 、 FC006_002 [#f2]_
       * - skip_detail_cd
         - 非表示にするソートキー [#f3]_  [#f4]_
       * - delete_flag
         - 0（0:未削除、1:削除）
       * - sort_key
         - 任意の数字（半角数字15桁、プリセット：「1」）※未使用項目です
       * - version_no
         - レコードのバージョンを表す番号（半角数字18桁、プリセット：「1」）
       * - create_user_cd、record_user_cd
         - 任意のユーザコード（プリセット：「init」）
       * - create_date、record_date
         - 任意の日時

    .. rubric:: 脚注

    .. [#f1] 参考情報として、任意の値を設定する項目にプリセットの値を記載しています。

    .. [#f2] パラメータ：「仕訳取引明細検索 債権債務出力項目非表示フラグ」の値で設定値が異なります。

           * 「0：表示」

              以下のそれぞれで行を追加する必要があります。

              * FC006_001（仕訳明細検索画面用）
              * FC006_002（仕訳取引明細検索画面用）
           * 「1：非表示」
              * FC006_001（仕訳取引明細検索画面／仕訳明細検索画面用）

    .. [#f3] skip_detail_cd カラムの値は、会計種別一覧（01_DesignDocument/01_第1編_業務共通設計/06_第6章_共通設計/04_第4節_各種台帳/12_会計種別一覧.xlsx）を参照してください。

           会計種別コードが「FC006」である会計種別明細名がコンボボックスのリストに表示されます。

           skip_detail_cd カラムの値には会計種別明細名が「非表示にしたいソートキーの名称」である会計種別明細コードの値を設定してください。

    .. [#f4] パラメータ：「仕訳取引明細検索 債権債務出力項目非表示フラグ」が「1：非表示」の場合、債権債務に関する項目はプリセットで絞り込まれているため、追加は不要です。
  
    .. note::

       追加 SQL のサンプルは下記になります。（例：元帳区分名を非表示にする場合）

       会社コード（company_cd）やスキップ明細コード（skip_detail_cd）を対象のコードに置き換えてください。

    ::

      insert into FMS_FC_LISTVALUE_CUT (company_cd, skip_cd, skip_detail_cd, delete_flag, sort_key, version_no, create_user_cd, create_date, record_user_cd, record_date) values ('DEFAULT_COMPANY', 'FC006_001', 'ledgerTypeName', '0', '1', '1', 'init', '2021-05-01 00:00:00.000', 'init', '2021-05-01 00:00:00.000');

.. _FMS_cookbook_setting_list_value_cut_sort_key-do-upd:


非表示にしたリスト値を表示するように戻す（非表示にしたリスト値のレコード更新）
------------------------------------------------------------------------------

  | :ref:`FMS_cookbook_setting_list_value_cut_sort_key-do-add` を実施後、非表示にしたリスト値を表示させたい場合に本手順を実施します。
  | 
  | 直接のDB操作を必要とします。
  | 以下の箇所を変更してください。（サーバの再起動は必要ありません）

  * 対象テーブル ::
  
      FMS_FC_LISTVALUE_CUT
  
  * 変更対象フィールド（フィールド名：設定値） ::
    
      delete_flag：1（0:未削除、1:削除）

    .. note::

       version_no 等の他の項目は任意で変更してください。
  
  * 変更条件
    
    変更対象のレコードは以下の条件で特定します。
    
    * company_cd
      
      * 対象の会社コード
    
    * skip_cd
      
       FC006_001 、 FC006_002 [#f2]_

    * skip_detail_cd
      
      * 非表示から表示に変更したいソートキー（会計種別コード：FC006 の「会計種別明細コード」の値） [#f3]_
