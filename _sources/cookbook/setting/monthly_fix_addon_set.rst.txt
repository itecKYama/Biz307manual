=======================================================================
原価計算にアドオン処理を組み込む
=======================================================================

プロジェクト原価管理の月次処理に |BIZ| 上でアドオン開発したプログラムを組み込むことができます。 

.. _FMS_cookbook_setting-monthly_fix_addon_set-execute_method:

実行メソッドを実装する
=======================================================================

プロジェクト原価管理の月次処理から起動できるようにするため、以下のように実行メソッドを実装します。

実行メソッド
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

  .. list-table::
     :widths: 5, 10, 5, 5, 30
     :header-rows: 1

     * - メソッド
       - 引数
       - 戻り値
       - 戻り値の型
       - 戻り値の内容
     * - execute
       - 実行パラメータモデル（ManyDealWithParameterDto）
       - 終了情報
       - Integer
       - | 0：正常
         | 1：エラー
         | 2：ワーニング
         | 3：仕訳作成 [#f1]_

  .. rubric:: 脚注

  .. [#f1] 正常終了時に会計インタフェーステーブルから仕訳を作成する場合に設定します。

  実行パラメータモデルにより、以下の項目が渡されます。

    .. list-table::
       :widths: 15, 15, 25
       :header-rows: 1

       * - 項目
         - 型
         - 内容
       * - 処理モード
         - Integer
         - | 0：月次処理
           | 1：月次処理事前チェック
           | 3：上記以外（月次確定）
       * - 会社コード
         - String
         - 会計コンテキストの会社コード
       * - 実行ID
         - String
         - 実行時に生成された実行ID
       * - ユーザコード
         - String
         - 会計コンテキストのユーザコード
       * - 組織コード
         - String
         - 会計コンテキストの所属組織コード
       * - 会計年度
         - Integer
         - 月次処理実行年月の会計年度
       * - 会計月度
         - Integer
         - 月次処理実行年月の会計月度
       * - 会計月度終了日
         - Date
         - 会計年度、会計月度により取得した月度終了日
       * - 拡張パラメータ
         - Map<String, String>
         - | key：原価計算クラス定義のパラメータキー1～3の値
           | value：バッチ処理手順テーブルの原価計算引数１～３の値
       * - グローバル変数モデル
         - GlobalValueContainer

.. _FMS_cookbook_setting-monthly_fix_addon_set-analyze_cd:

分析コードを登録する
=======================================================================

以下のメニューより、分析種別：COSEQ（原価計算処理区分）に対し、アドオン機能の分析コードを登録します。

* メニュー ::

    Biz∫ APF アドミニストレーション 
      マスタ管理
        分析コード
          分析コード管理

  .. note::

    * 後続のバッチ処理手順を登録する際、本手順で登録した分析コードを原価計算処理区分に設定します。

    * | アドオン機能用の分析コード：51（アドオン機能１）～59（アドオン機能９）がプリセットされるため、分析コード名などを変更して利用してください。
      | 追加も可能です。追加する場合は分析コードを2桁で登録してください。

.. _FMS_cookbook_setting-monthly_fix_addon_set-cost_calculation_class:

原価計算クラス定義を登録する
=======================================================================

原価計算クラス定義エンティティ（fms_jc_cost_calculation_class）に対してデータの登録を行います。

以下の各項目に対する説明を参考に原価計算クラス定義エンティティを編集して下さい。

  .. list-table::
     :widths: 8, 30, 15
     :header-rows: 1

     * - 項目名
       - 説明
       - 例
     * - 会社コード
       - 原価計算処理手順を組み込む会社コードを設定します。
       - BZ1
     * - 原価計算処理コード
       - 分析種別コード：COSEQ（原価計算処理区分）に登録したアドオン機能の分析コードを設定します。
       - 51
     * - 原価計算処理名
       - アドオン処理名を設定します。
       - アドオン機能１
     * - クラス名
       - アドオン処理の実行メソッドを実装したクラス名を設定します。
       - com.biz_integral.fms.jc.domain.logic.MonthlyFixAddon1Logic
     * - パラメータキー1
       - | 拡張パラメータのキー値として、任意の文字列を設定します。
         | 実装時、拡張パラメータから原価計算引数１の区分値を取得する際に利用します。 [#f2]_
       - scope [#f3]_
     * - パラメータキー2
       - | 拡張パラメータのキー値として、任意の文字列を設定します。
         | 実装時、拡張パラメータから原価計算引数２の区分値を取得する際に利用します。 [#f2]_
       - 設定なし
     * - パラメータキー3
       - | 拡張パラメータのキー値として、任意の文字列を設定します。
         | 実装時、拡張パラメータから原価計算引数３の区分値を取得する際に利用します。 [#f2]_
       - 設定なし

  .. rubric:: 脚注

  .. [#f2] 原価計算引数1～3の区分値については、台帳の『07_区分値一覧.xlsx』を参照してください。
  .. [#f3] 後続のバッチ処理手順の登録にて原価計算引数１に「2」（四半期/２回目以降）を設定した場合、拡張パラメータには key：scope、value：2として設定されます。
