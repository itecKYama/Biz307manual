.. _FMS_cookbook_setting_006:

===================================================================
ページング機能を持つグリッドの1頁あたりの最大表示件数を変更する
===================================================================

ページング機能を持つグリッドにおいて、1頁あたりの最大表示件数を変更します。
設定ファイルに値を定義することで、レイアウト定義XMLを更新せずに、カスタマイズを実現可能とします。

.. note:: 

  デフォルト（出荷時）では、本設定は行われていません。
  レイアウト定義XML上で、ページャーに設定された値(limit)が有効になります。

  前提条件及び注意事項を確認した上で、実施の有無を検討してください。

.. _FMS_cookbook_setting_006-pre:

前提条件
===================================================

* 対象
  
  ページャーが設定されたグリッド

  .. note::
    
    ページング機能を持たないグリッドについては、本カスタマイズの対象外となります。

.. _FMS_cookbook_setting_006-do:

実行手順
===================================================

* 画面ソース内の、jsonファイルを更新します。::

  [WEBサーバ]/fms/[モジュールID]/extension/layoutCustomParam.json

* 設定方法::

  [レイアウトID].pager.[ページャーコンポーネント名].limitに値を設定します。


.. _FMS_cookbook_setting_006-ex:

設定例
===================================================

* パラメータ検索画面の2つのグリッドの設定を変更する場合

  .. code-block:: js

    {
        "fms_fc_parameterMaintenance_search" : {
            "pager" : {
                "pgParameterListDefault" : {
                    "limit" : 40
                },
                "pgParameterListDisplayControl" : {
                    "limit" : 30
                }
            }
        }
    }

* パラメータ検索画面の1つのグリッドの設定を変更する場合

  もう1つのグリッドは未設定。デフォルトの値が適用されます。

  .. code-block:: js

    {
        "fms_fc_parameterMaintenance_search" : {
            "pager" : {
                "pgParameterListDefault" : {
                    "limit" : 40
                }
            }
        }
    }

.. _FMS_cookbook_setting_006-attention:

注意事項
===================================================

* 本機能を使用してもグリッドの高さは調整されません。

  .. note:: 

    デフォルトの状態より大きな値を設定した場合は、縦スクロールが表示されます。

* 設定した値の妥当性検証は行っていませんので、不正な値を設定すると、エラーが発生する可能性があります。

  .. note:: 

    設定後は必ず動作確認を行ってください。

* 値を変更した場合は、性能上問題ないか、検証を行ってください。

  .. note:: 

    設定可能な値の上限は設定していませんが、どんな設定値でも性能上問題ないことを保証するものではありません。
