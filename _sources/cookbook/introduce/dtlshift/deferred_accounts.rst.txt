===================================================
経過勘定対象取引の再登録（当年度発生分）
===================================================

期中導入の場合、当年度中に発生している経過勘定対象取引の移行を行う。

.. _FMS_cookbook_introduce_dtlshift-deferred_accounts-startConditions:

着手条件
===================================================

* 期首残高生成仕訳取込を終えていること。

* 経過勘定振替マスタの登録を終えていること。

.. _FMS_cookbook_introduce_dtlshift-deferred_accounts-do:

実行手順
===================================================

期中に導入する場合は、当年度中に発生している経過勘定対象の取引を |FMS| に移行する必要がありますが、移行元の経過勘定の計上方法により、移行方法が異なります。

1. 経過勘定の対象となる取引が発生した際、全額を費用/収益として計上した後、月次サイクルで経過勘定の振替を行っている場合

  移行前に発生していた経過勘定振替仕訳と経過勘定取崩仕訳を削除して、 |FMS| の経過勘定振替で作成し直します。

2. 経過勘定を直接計上し、毎月取崩しの仕訳を計上していた場合

  移行前に発生していた経過勘定取崩仕訳を移行し、残りの振替期間の取崩仕訳を |FMS| の経過勘定振替で作成します。

.. _FMS_cookbook_introduce_dtlshift-deferred_accounts-do-da:

経過勘定の対象となる取引が発生した際、全額を費用/収益として計上した後、月次サイクルで経過勘定の振替を行っている場合
--------------------------------------------------------------------------------------------------------------------------

**想定される移行元の仕訳例（6月1日運用開始を想定した場合）**

  .. figure:: ./images/deferred_accounts_001.png
     :width: 300px
     

上記のような運用を行っている場合には、以下の手順で移行を行います。

1. ①～④の仕訳明細を取り込むため、一括取込用のファイルを作成します。

  取り込み対象の仕訳明細を元に、設定シート「一括取込シート_仕訳.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備してください。

  .. note::
  
    ①の取込みデータの借方科目（前受収益の場合には、貸方）については、経過勘定振替マスタに登録している必要があります。

2. 仕訳の一括登録を行います。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「F6:ファイル選択」を押下し、ファイルを指定後、「F5:取込」より登録します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳取込処理
            仕訳一括取込

3.  ②～④の経過勘定振替仕訳と経過勘定取崩仕訳を削除します。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、計上日と仕訳一括取込みを行った際の実施番号をキーに「F6:検索」を押下し、②～④に該当する仕訳の「更新」ボタンを押下し、「仕訳登録」画面にて、「F10:削除」を押下し、仕訳の削除を行います。

  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳入力
            仕訳登録

4.  経過勘定振替実行（仮実行）を行う。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、対象年月に前月までの年月を入力し、「F5:仮実行」を押下し、経過勘定振替実行を行います。4.～6.までの流れを前月分まで繰り返し実行します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          経過勘定管理
            経過勘定振替

  .. note::
  
    上記の例の場合、4月と5月の実行を4.～6.の手順で実行します。

5.  仮実行の結果を確認する。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、経過勘定台帳を取得し、勘定科目コード、計上組織をキーに、振替られた前払費用、前受収益の金額が一致することを確認します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          経過勘定管理
            経過勘定台帳
  
  * 実行条件
  
    * 対象期間
      
      4.で指定した年月を指定
    
    * 仮実行
    
      仮実行含む

6.  経過勘定振替実行（確定）を行う。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、4.で仮実行した結果に対して、「確定」ボタンを押下し、経過勘定振替の本実行を行います。

  * メニュー ::

      Biz∫ 会計
        一般会計
          経過勘定管理
            経過勘定振替


.. _FMS_cookbook_introduce_dtlshift-deferred_accounts-do-cross:

経過勘定を直接計上し、毎月取崩しの仕訳を計上していた場合
--------------------------------------------------------------------------------------------------------------------------

**想定される移行元の仕訳例（6月1日運用開始を想定した場合）**

  .. figure:: ./images/deferred_accounts_002.png
     :width: 300px

上記のような運用を行っている場合には、以下の手順で移行を行います。

1. ①～③の仕訳明細を取り込むため、一括取込用のファイルを作成します。

  取り込み対象の仕訳明細を元に、設定シート「一括取込シート_仕訳.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備してください。

2. 仕訳の一括登録を行います。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「F6:ファイル選択」を押下し、ファイルを指定後、「F5:取込」より登録します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳取込処理
            仕訳一括取込

3. ①に対する振替仕訳を計上する。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより①の未取崩し分に対する振替仕訳を登録する。

  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳入力
            仕訳登録

  * ①の取崩し残に対する振替仕訳例
  
    .. figure:: ./images/deferred_accounts_003.png
       :width: 300px
    
    * 借方に指定する科目（前受収益の場合には、貸方）は、経過勘定振替マスタで設定した科目を使用すること。
    
    * 振替期間は当月から振替終了月までの期間を指定すること。
