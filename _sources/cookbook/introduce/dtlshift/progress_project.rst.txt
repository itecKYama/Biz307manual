=================================================================================
進行基準および原価回収基準プロジェクトの移行用の仕訳の登録
=================================================================================

以下の仕訳を登録します。

* 進行基準プロジェクト運用開始における進捗率算出のための仕訳
* 原価回収基準プロジェクト運用開始における契約資産残高を計上する仕訳

.. _FMS_cookbook_introduce_dtlshift-progress_project-startConditions:

着手条件
===================================================

* 運用開始の前年度までの明細取り込みを完了していること。

.. _FMS_cookbook_introduce_dtlshift-progress_project-do:

実行手順
===================================================

1. 月次処理年月を確認します。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「月次処理」画面を起動し、実行年月を確認します。
  
  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          更新処理
            月次処理

  * 実行年月が運用開始の前月であることを確認します。運用開始の前月となっていない場合は :ref:`FMS_introduce_module_jc-batch_month` で変更を行います。

2. 仕訳明細を取り込むため、一括取込用のファイルを作成します。

  設定シート「一括取込シート_仕訳.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備してください。

  「一括取込シート_仕訳.csv」は以下のように作成します。

  .. list-table::
     :widths: 2, 4, 4
     :header-rows: 1

     * - 項目名
       - 借方設定内容
       - 貸方設定内容
     * - 計上日
       - 運用開始の前月を設定します。
       - 運用開始の前月を設定します。
     * - 勘定科目コード
       - 製造原価科目
       - 売上原価
     * - 分析コード [#f1]_
       - プロジェクトコード
       - プロジェクトコード

  .. rubric:: 脚注

  .. [#f1] パラメータ「プロジェクトの分析フィールド」で設定された分析コード

3. 仕訳の一括登録を行います。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「F6:ファイル選択」を押下し、ファイルを指定後、「F5:取込」より登録します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳取込処理
            仕訳一括取込

4. 月次処理を行います。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、「F5:実行」ボタンを押下して月次処理を行います。
  
  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          更新処理
            月次処理

5. 月次処理で作成された進行基準収益および原価回収基準収益の仕訳を削除します。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、「仕訳検索」画面を起動します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳入力
            仕訳検索

  * 以下の条件で「F6:検索」ボタンを押下します。

    * 計上日

      当月（運用開始の前月）

    * 作成ｱﾌﾟﾘｹｰｼｮﾝ分類

      収益計上

  * 検索された仕訳を削除します。

.. _FMS_cookbook_introduce_dtlshift-progress_project-endConditions:

完了条件
===================================================

* 以下のメニューより、試算表を取得し、会社コード、計上組織コード、勘定科目コード、補助科目コードをキーに、契約資産と当期利益の金額が残高移行後の金額と一致することを確認します。

  * メニュー ::

      Biz∫ 会計
        一般会計
          帳票出力
            試算表

  * 実行条件

    * 対象期間

      当月（運用開始の前月）

    * 科目構成

      科目構成コード

    * 対象組織

      全社

    * 集計科目を表示する

      チェック

    * 元帳区分

      共通＋日本

    * 決算

      全ての種別を選択する

    * 仮仕訳

      選択なし

* 進行基準プロジェクトの場合、以下のメニューより、売上／売上原価推移表を出力し、進捗率が計算されていることを確認します。

  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          帳票出力処理
            レポート
              売上／売上原価推移表

  * 実行条件

    * 対象年度

      運用開始の前月の年度

    * 原価差額配賦

      含む

    * 組織グループ

      全社
