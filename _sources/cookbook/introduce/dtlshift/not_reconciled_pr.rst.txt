===================================================
未消込債権債務の登録
===================================================

移行対象年度の未消込の債権・債務の仕訳を取り込みます。

.. _FMS_cookbook_introduce_dtlshift-not_reconciled_pr-startConditions:

着手条件
===================================================

* 移行対象年度の消込済分の移行が完了していること。

* :ref:`FMS_cookbook_introduce_dtlshift-master` を実施している場合、 :ref:`FMS_cookbook_introduce_dtlshift-is_balance` が完了していること。

.. _FMS_cookbook_introduce_dtlshift-not_reconciled_pr-do:

実行手順
===================================================

移行対象年度の未消込の債権データ・債務データを取り込みます。

.. note::
  
  取込対象の債務仕訳を元に、シート「一括取込シート_債権.csv」「一括取込シート_債務.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備します。
  
|FMS_ADM| アカウントでポータル画面にログインし、以下のそれぞれのメニューより「F6:ファイル選択」を押下し、ファイルを指定後、取込時の仕訳状態を「本仕訳」として、「F5:取込」より登録します。


* 債権データ取込みのメニュー ::

    Biz∫ 会計
      債権管理
        債権管理
          債権データ取込

* 債務データ取込みのメニュー ::

    Biz∫ 会計
      債務管理
        債務管理
          債務データ取込
