===================================================
未成プロジェクト残高仕訳の登録
===================================================

移行対象年度の未成プロジェクト残高を仕訳として登録します。

.. _FMS_cookbook_introduce_dtlshift-project_cost-startConditions:

着手条件
===================================================

* 運用開始の前年度までの明細取り込みを完了していること。

.. _FMS_cookbook_introduce_dtlshift-project_cost-do:

実行手順
===================================================

1. 月次処理年月を確認します。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「月次処理」画面を起動し、実行年月を確認します。
  
  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          更新処理
            月次処理

  * 実行年月が運用開始の前月であることを確認します。運用開始の前月となっていない場合は :ref:`FMS_introduce_module_jc-batch_month` で変更を行います。

2. 仕訳明細を取り込むため、一括取込用のファイルを作成します。

  設定シート「一括取込シート_仕訳.csv」の所定のフォーマットに従って項目を埋めたcsvファイルを準備してください。

  「一括取込シート_仕訳.csv」は以下のように作成します。

  .. list-table::
     :widths: 2, 4, 4
     :header-rows: 1

     * - 項目名
       - 借方設定内容
       - 貸方設定内容
     * - 計上日
       - 運用開始の前月を設定します。
       - 運用開始の前月を設定します。
     * - 勘定科目コード
       - 製造原価科目
       - 原価計算種別の原価振替科目（仕掛品など）
     * - 分析コード [#f1]_
       - プロジェクトコード
       - [#f2]_

  .. rubric:: 脚注

  .. [#f1] パラメータ「プロジェクトの分析フィールド」で設定された分析コード

  .. [#f2] :ref:`FMS_cookbook_introduce_balanceshift` でプロジェクトコード別に原価振替科目（仕掛品など）の残高を作成している場合、プロジェクトコードを設定します。

3. 仕訳の一括登録を行います。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより「F6:ファイル選択」を押下し、ファイルを指定後、「F5:取込」より登録します。
  
  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳取込処理
            仕訳一括取込

4. 月次処理を行います。

  |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、「F5:実行」ボタンを押下して月次処理を行います。
  
  * メニュー ::

      Biz∫ 会計
        プロジェクト原価管理
          更新処理
            月次処理

  .. note::

    :ref:`FMS_cookbook_introduce_dtlshift-progress_project` を行う場合、本処理はスキップして、 :ref:`FMS_cookbook_introduce_dtlshift-progress_project` の手順の中で実行します。

.. _FMS_cookbook_introduce_dtlshift-project_cost-endConditions:

完了条件
===================================================

* 以下のメニューより、試算表を取得し、会社コード、計上組織コード、勘定科目コード、補助科目コードをキーに、原価振替科目（仕掛品など）の金額が残高移行後の金額と一致することを確認します。

  * メニュー ::

      Biz∫ 会計
        一般会計
          帳票出力
            試算表

  * 実行条件

    * 対象期間

      当月（運用開始の前月）

    * 科目構成

      科目構成コード

    * 対象組織

      全社

    * 集計科目を表示する

      チェック

    * 元帳区分

      共通＋日本

    * 決算

      全ての種別を選択する

    * 仮仕訳

      選択なし
