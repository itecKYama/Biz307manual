===================================================
帳票レイアウトを使い分けるための設定を行う
===================================================

標準のレイアウトとは別に、独自に追加したレイアウトを指定して帳票を出力できるようにします。

レイアウトを指定できる帳票は、以下となります。

  * 総勘定元帳

  * 債権申請書
           
  * 請求書

  * 支払調書

  * 資産登録申請書

.. _FMS_cookbook_introduce_reportLayout-prepare:

前提条件
===================================================
* 帳票レイアウトファイルを帳票サーバーに配置していること。

  フレキシブルレポートを利用してレイアウトを作成した場合には、帳票レイアウトファイルを帳票サーバーに配置する必要はありません。

.. _FMS_cookbook_introduce_reportLayout-do:

実行手順
===================================================

1. 帳票設定の登録
  
  追加したレイアウトに対して帳票設定を登録します。

  * メニュー ::

      Biz∫ APF アドミニストレーション 
        システム管理
          帳票設定
            帳票設定

  * 設定内容
  
    以下の表にしたがい、各項目に値を設定してください。
  
    .. list-table::
       :widths: 1, 2, 4
       :header-rows: 1

       * - 項目
         - 設定値
         - 備考
       * - アプリケーションID
         - fms
         - アプリケーションIDを間違えると、印刷実行ダイアログで検索対象となりません。
       * - モジュールID
         - 総勘定元帳： gl

           債権申請書： pr
           
           請求書： pr

           支払調書： pr

           資産登録申請書： fa
         - モジュールIDを間違えると、印刷実行ダイアログで検索対象となりません。
       * - 帳票コード
         - 任意
         - 
       * - 製品区分
         - SVF For PDF
         -
       * - 帳票レイアウトファイルパス
         - 任意
         - 帳票サーバに配置したレイアウトファイルのファイルパス
         
           フレキシブルレポートを利用してレイアウトを作成した場合には、設定する必要はありません。
       * - 帳票ファイル表示名
         - 任意
         - 帳票ファイル表示名は、以下の場面で表示されます。
         
           * 印刷実行ダイアログでレイアウトを選択するときの帳票ファイル表示名
            
           * ファイルダウンロードダイアログのファイル名
         
           例） XXX社用請求書

       * - 削除フラグ
         - 活動中
         -

    
  .. note::

    フレキシブルレポートを利用してレイアウトを作成した場合は、  |BAPF| のフレキシブルレポート `フレキシブルレポート決定表`_ を参照してフレキシブルレポート決定表を登録してください。


2. 帳票グループ関連の登録

  追加したレイアウトと帳票グループの関連付けを登録します。以下のメニューから帳票グループを選択し、帳票グループ関連を追加します。

  * メニュー ::

      Biz∫ APF アドミニストレーション 
        システム管理
          帳票設定
            帳票グループ管理

  * 帳票グループ

    以下の表にしたがい、帳票グループを選択してください。
  
    .. list-table::
       :widths: 2, 2, 2
       :header-rows: 1

       * - 帳票
         - 帳票グループコード
         - 帳票グループ名
       * - 総勘定元帳
         - generalLedger
         - 総勘定元帳
       * - 債権申請書
         - arRequestApplication
         - 債権申請書
       * - 請求書
         - invoice
         - 請求書
       * - 支払調書
         - paymentRecord
         - 支払調書
       * - 資産登録申請書
         - assetAcquisitionApplication
         - 資産登録申請書

  * 帳票グループ関連の設定内容
  
    以下の表にしたがい、各項目に値を設定してください。
  
    .. list-table::
       :widths: 1, 2, 4
       :header-rows: 1

       * - 項目
         - 設定値
         - 備考
       * - 帳票設定ID
         - 1で登録した帳票レイアウトの帳票設定ID
         - 帳票コード、帳票ファイル表示名から対象を判定します。
       * - ソートキー
         - 任意
         - 印刷実行ダイアログでレイアウトを選択するときに、ソートキーの昇順で表示されます。
       * - デフォルトフラグ
         - 任意
         - デフォルトにすることで、印刷実行ダイアログの項目「帳票レイアウト」に初期表示される値となります。（請求書を除く）

3. 取引先別帳票レイアウト決定表の登録

  請求先毎に請求書のレイアウトをあらかじめ指定したい場合のみ、取引先別帳票レイアウト決定表を登録します。

  取引先別帳票レイアウト決定表の登録につきましては、  |BAPF| の取引先マスタ拡張 モジュール `取引先別に帳票レイアウトを設定する`_ を参照してください。


.. _FMS_cookbook_introduce_reportLayout-endConditions:

完了条件
===================================================
該当の帳票出力画面にて、追加したレイアウトを指定して帳票出力できることを確認します。
