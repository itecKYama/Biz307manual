===================================================
仕訳パターン_自動消込手数料仕訳明細の登録
===================================================
債権管理の「仮受金自動消込」画面で実行処理、「振込入金一括更新」画面の自動消込処理を行った際に作成される入金仕訳には、振込手数料明細が自動的に生成されます。

この仕訳明細を作成するために、仕訳パターンを登録し、その仕訳パターンのコードをパラメータに設定します。

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_auto_Rcncl_fee_dtl-startConditions:

着手条件
===================================================
:ref:`FMS_introduce_core` までの作業を終えていること。

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_auto_Rcncl_fee_dtl-do:

実行手順
===================================================

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_auto_Rcncl_fee_dtl-do-pattern:

仕訳パターンの登録
---------------------------------------------------
Biz∫会計管理者アカウントでポータル画面にログインし、「仕訳登録」画面を表示してください。

* メニュー ::

    Biz∫ 会計
      一般会計
        仕訳入力
          仕訳登録

1. 「仕訳登録」画面から、以下のように仕訳を入力してください。

  * 仕訳のヘッダ項目について

    * 伝票摘要に、登録する仕訳パターンの名称を入力してください。

  * 仕訳の明細項目について

    * 借方を2行入力してください。

    * 仕訳パターンの貸方の値は使用されません。

    * 仕訳パターンの値が適用される明細項目は下表のとおりです。

      .. note::

        予算コードは :ref:`FMS_introduce_module_ma-budget_import` で登録するものを設定してください。

      .. list-table::
         :widths: 5, 5, 5
         :header-rows: 1

         * - 項目
           - 借方1行目
           - 借方2行目
         * - 勘定科目
           - 振込手数料用の勘定科目コード
           - 許容差額用の勘定科目コード
         * - 補助科目
           - 振込手数料用の補助科目コード
           - 許容差額用の補助科目コード
         * - 消費税
           - 振込手数料用の消費税コード
           - 許容差額用の消費税コード
         * - 税処理区分
           - 振込手数料用の税処理区分
           - 許容差額用の税処理区分
         * - 予算コード
           - 振込手数料用の予算コード
           - 許容差額用の予算コード
         * - キャッシュフローコード
           - 振込手数料用のキャッシュフローコード
           - 許容差額用のキャッシュフローコード
         * - 分析フィールド1～10、21～30
           - 振込手数料用の分析フィールド1～10、21～30
           - 許容差額用の分析フィールド1～10、21～30
         * - 分析テキスト11～20、31～40
           - 振込手数料用の分析テキスト11～20、31～40
           - 許容差額用の分析テキスト11～20、31～40
         * - 明細メモ
           - 振込手数料用の明細メモ
           - 許容差額用の明細メモ
         * - その他の項目
           - 仕訳パターンの値は使用されません
           - 仕訳パターンの値は使用されません

2. 仕訳入力後、「SF12:パターン」ボタンを押下し、仕訳パターン登録ダイアログを表示します。

3. 任意のパターンコードを入力し、「F5:登録」ボタンを押下して仕訳パターンを登録してください。

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_auto_Rcncl_fee_dtl-do-parameter:

パラメータの設定
---------------------------------------------------
Biz∫会計管理者アカウントでポータル画面にログインし、対象モジュール「債権債務」のパラメータ「仕訳パターン_自動消込手数料仕訳明細」に登録した仕訳パターンのコードを設定してください。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          基本設定管理
            パラメータ管理

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_auto_Rcncl_fee_dtl-endConditions:

完了条件
===================================================
* 登録した仕訳パターンコードが「パラメータ」検索画面のパラメータ「仕訳パターン_自動消込手数料仕訳明細」に設定されていることを確認します。
* 仕訳パターンマスタのプルーフリストを出力し、仕訳パターンコードが正しく登録されていることを確認します。
