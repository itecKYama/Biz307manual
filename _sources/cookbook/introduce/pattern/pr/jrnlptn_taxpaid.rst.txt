=======================================================
仕訳パターン_締時一括消費税仕訳（仮払消費税用）の登録
=======================================================
パラメータ「適格請求書消費税合計計算区分」が「税抜金額金額」に設定されている状態で、債務管理の「一括支払申請」画面で実行処理を行った際、自動的に締時一括消費税仕訳（仮払消費税）を作成します。

この仕訳を作成するために、仕訳パターンを登録し、その仕訳パターンのコードをパラメータに設定します。

  .. note::

    パラメータ「適格請求書消費税合計計算区分」が「税込金額」に設定されている場合は、 :ref:`FMS_cookbook_introduce_pattern_pr-jrnlptn_taxincluded_taxpaid` を参照してください。

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_taxpaid-startConditions:

着手条件
===================================================
:ref:`FMS_introduce_core` までの作業を終えていること。

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_taxpaid-do:

実行手順
===================================================

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_taxpaid-do-pattern:

仕訳パターンの登録
---------------------------------------------------
Biz∫会計管理者アカウントでポータル画面にログインし、「仕訳登録」画面を表示してください。

* メニュー ::

    Biz∫ 会計
      一般会計
        仕訳入力
          仕訳登録

1. 「仕訳登録」画面から、以下のように仕訳を入力してください。

  * 仕訳のヘッダ項目について

    * 伝票摘要に、登録する仕訳パターンの名称を入力してください。

  * 仕訳の明細項目について

    * 借方1行のみ入力してください。（2行目以降は、無視されます）

    * 仕訳パターンの貸方の値は使用されません。

    * 仕訳パターンの値が適用される明細項目は下表のとおりです。

      .. note::

        予算コードは :ref:`FMS_introduce_module_ma-budget_import` で登録するものを設定してください。

      .. list-table::
         :widths: 5, 5
         :header-rows: 1

         * - 項目
           - 借方
         * - 税処理区分
           - 仮払消費税用の税処理区分
         * - 明細摘要
           - 仮払消費税用の明細摘要
         * - 予算コード
           - 仮払消費税用の予算コード
         * - キャッシュフローコード
           - 仮払消費税用のキャッシュフローコード
         * - 分析フィールド1～10,21～30
           - 仮払消費税用の分析フィールド1～10,21～30
         * - 分析テキスト11～20,31～40
           - 仮払消費税用の分析テキスト11～20,31～40
         * - 明細メモ
           - 仮払消費税用の明細メモ
         * - その他の項目
           - 仕訳パターンの値は使用されません

2. 仕訳入力後、「SF12:パターン」ボタンを押下し、仕訳パターン登録ダイアログを表示します。

3. 任意のパターンコードを入力し、「F5:登録」ボタンを押下して仕訳パターンを登録してください。

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_taxpaid-do-parameter:

パラメータの設定
---------------------------------------------------
Biz∫会計管理者アカウントでポータル画面にログインし、対象モジュール「債権債務」のパラメータ「仕訳パターン_締時一括消費税仕訳（仮払消費税用）」に登録した仕訳パターンのコードを設定してください。

* メニュー ::

    Biz∫ 会計
      会計コア
        マスタメンテナンス
          基本設定管理
            パラメータ管理

.. _FMS_cookbook_introduce_pattern_pr-jrnlptn_taxpaid-endConditions:

完了条件
===================================================
* 登録した仕訳パターンコードが「パラメータ」検索画面のパラメータ「仕訳パターン_締時一括消費税仕訳（仮払消費税用）」に設定されていることを確認します。
* 仕訳パターンマスタのプルーフリストを出力し、仕訳パターンコードが正しく登録されていることを確認します。
