===================================================
支払調書出力明細の登録
===================================================

導入年に |FMS| 債務管理モジュールの支払調書を税務署に提出する場合のみ実施する必要があります。

.. _FMS_cookbook_introduce_balanceshift_pr-payment_record-startConditions:

着手条件
===================================================

:ref:`FMS_introduce` の以下の項目までの作業を終えていること。

* :ref:`FMS_introduce_preparation`
* :ref:`FMS_introduce_baseset`
* :ref:`FMS_introduce_core`
* :ref:`FMS_introduce_workflow`
* :ref:`FMS_introduce_module_pr`

.. _FMS_cookbook_introduce_balanceshift_pr-payment_record-do:

実行手順
===================================================

1. |FMS_ADM| アカウントでポータル画面にログインし、以下のメニューより、試算表を出力し、登録前の残高を確認します。

  * メニュー ::

      Biz∫ 会計
        一般会計
          帳票出力処理
            試算表
  
  .. note::
  
    計上日を導入年の1月1日から導入開始日の前日までとした条件で試算表を出力します。

2. 以下のメニューより、導入年の1月1日から導入開始日の前日までに源泉徴収を行った取引を登録します。

  * メニュー ::

      Biz∫ 会計
        債務管理
          支払管理
            支払依頼登録

  .. note::
  
    源泉情報（源泉タブ）を正しく設定し登録してください。

3. 2.で登録した支払依頼申請の逆仕訳を登録します。

  * メニュー ::

      Biz∫ 会計
        一般会計
          仕訳入力
            仕訳登録

  .. note::
  
    計上日は、支払依頼申請と同日で登録してください。

  **登録例**
  
  .. figure:: ../images/payment_record_001.png
     :width: 500px

.. _FMS_cookbook_introduce_balanceshift_pr-payment_record-endConditions:

完了条件
===================================================

* 以下のメニューより、計上日を導入年の1月1日から導入開始日の前日までとした条件で、預り源泉税一覧表を取得し、登録内容を確認します。

  * メニュー ::
  
      Biz∫ 会計
        債務管理
          支払管理
            預り源泉税一覧表

* 以下のメニューより、試算表を取得し、残高が一致することを確認します。

  計上日を導入年の1月1日から導入開始日の前日までとした条件で試算表を取得し、 :ref:`FMS_cookbook_introduce_balanceshift_pr-payment_record-do` で出力した試算表を比較し、支払依頼登録、仕訳登録で登録した勘定科目の残高が合致している事を確認します。

  * メニュー ::
  
      Biz∫ 会計
        債務管理
          支払管理
            預り源泉税一覧表

  .. note::
  
    設定例の場合は、業務委託費、現金、源泉預り金の残高が合致している事を確認します。
