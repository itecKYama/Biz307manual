===================================================
プロジェクト一括取込ジョブ実行
===================================================
以下は、プロジェクト一括取込ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_jc_prjImport
  -certUserCd=B12200 -certUserPassword=PASSWORD 
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DreadStartCol=2 -DfilePath=C:\batch\import -DfileName=import_file.csv


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - readStartCol [#doption]_
     - 読込開始行を指定します。
   * - filePath [#doption]_
     - ファイルパス（フォルダ）を指定します。
   * - fileName [#doption]_
     - ファイル名を指定します。

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
