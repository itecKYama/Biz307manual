===================================================
給与仕訳取込ジョブ実行
===================================================
以下は、給与仕訳取込ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_jc_laborJrnl
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DprocessId=ZGKIKRTK2 -Djkbn=1
  -DuploadPath1=C:\batch\import\import_file.csv -Dsyokbn=0
  -Dkyuyokbn=0 -Dmibakbn=9 -Dkomoku=50


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - processId [#doption]_
     - プログラム識別子（固定文字列”ZGKIKRTK2”）を指定します。
   * - jkbn [#doption]_
     - 実行区分（固定値”1”）を指定します。
   * - uploadPath1 [#doption]_
     - ファイル名（フルパス）を指定します。
   * - syokbn [#doption]_
     - 処理区分（固定値”0”）を指定します。
   * - kyuyokbn [#doption]_
     - 給与区分（0:例月、1:賞与、2:未払）を指定します。
   * - mibakbn [#doption]_
     - 未払区分（0:未払、1:洗替え、9:その他）を指定します。
   * - komoku [#doption]_
     - 給与ファイルのCSV項目数を指定します。


.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
