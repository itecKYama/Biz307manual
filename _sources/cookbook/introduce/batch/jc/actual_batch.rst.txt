===================================================
稼働実績取込ジョブ実行
===================================================
以下は、稼働実績取込ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_jc_actualOperationImport
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DprocessId=ZFOKADOJT2
  -DuploadPath=C:\batch\import\import_file.csv -Dpkbn=0


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - processId [#doption]_
     - プログラム識別子（固定文字列”ZFOKADOJT2”）を指定します。
   * - uploadPath [#doption]_
     - 取込ファイル名（フルパス）を指定します。
   * - pkbn [#doption]_
     - 取込方法（0:洗い替え、1:追加）を指定します。

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
