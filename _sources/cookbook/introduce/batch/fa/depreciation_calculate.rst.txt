===================================================
償却計算ジョブ実行
===================================================
以下は、償却計算ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_depreciationCalculate
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DcreatePrvsnlDprctnJrnlFlg=1 -DdepartmentCd=12200
  -Dexecute=0

設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - | 外部ソフトウェア接続URLを指定します。
       | http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - createPrvsnlDprctnJrnlFlg [#doption]_
     - 仮実行時、減価償却費仕訳を計上する場合は"1"、計上しない場合は"0"を指定します。
   * - departmentCd [#doption]_
     - 起票組織コードを指定します。
   * - execute [#doption]_
     - 仮実行の場合は"0"、確定実行の場合は"1"を指定します。

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
