===================================================
振込依頼実行ジョブ実行
===================================================
以下は、振込依頼実行ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_pr_paymentRequestPackage
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DcompanyBankAccountCd=001 -DgroupClassCd=11
  -DlineContactType=1 -DdepartmentCd=12200
  -DaddEOF=0 -DtransferDayCalculateType=1
  -DtransferDay=3 -DautomaticInterfaceFolderPath=\FB
  -DfbDispalyFileName=FBデータ   -DtransferDisplayFileName=依頼書

設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - | 外部ソフトウェア接続URLを指定します。
       | http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - companyBankAccountCd [#doption]_
     - 社内口座コードを設定します。
   * - groupClassCd [#doption]_
     - | 振込依頼を印刷・データ出力する際のフォーマットを設定します。
       | 11.給与振込
       | 21.総合振込
   * - lineContactType [#doption]_
     - | 振込処理の方法を設定します。「回線」を選択するとFBデータが、 「窓口」を選択すると総合振込依頼書が出力されます。
       | 1.回線
       | 2.窓口
   * - departmentCd [#doption]_
     - 起票組織コードを設定します。
   * - addEOF [#doption]_
     - | 出力ファイルの末尾にEOFを付与するかを設定します。
       | 0.EOF付与しない
       | 1.EOF付与
   * - transferDayCalculateType [#doption]_
     - | 振込日までの日数の計算方法を設定します。
       | 1.日数
       | 2.営業日数
   * - transferDay [#doption]_
     - ジョブの実行日から振込日までの日数を設定します。
   * - automaticInterfaceFolderPath [#doption]_
     - 出力ファイルの出力先フォルダを、パブリックストレージパスからの相対パスで設定します。
   * - fbDispalyFileName [#doption]_
     - 回線窓口区分が回線の場合、自動連携フォルダパスに出力するFBデータの表示名を設定します。設定しない場合、「振込依頼実行」がファイル名に含まれます。
   * - transferDisplayFileName [#doption]_
     - 回線窓口区分が窓口の場合、自動連携フォルダパスに出力する振込依頼書の表示名を設定します。設定しない場合、「振込依頼書」がファイル名に含まれます。

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
