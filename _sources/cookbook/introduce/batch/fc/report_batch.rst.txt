===================================================
帳票出力ジョブ実行
===================================================
以下は、帳票出力ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_fc_report_batch
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DcompanyCd=BZ1 -DoutputProcessingType=1
  -Dcomment=試算表 -DreportId=trialBalance
  -DtemplateId=11 -DfileItmTmpltId=22


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - companyCd [#doption]_
     - 月次更新実行及び仮実行を行う会社コードを指定します。
   * - outputProcessingType [#doption]_
     - 帳票出力を実施するかファイル出力を実施するかを表す区分値を指定します。

       1：帳票出力処理を実施、2：ファイル出力処理を実施
   * - comment [#doption]_
     - 帳票出力で実行される非同期タスクのコメントを指定します。

   * - reportId [#doption]_
     - 出力する帳票IDを指定します。

   * - templateId [#doption]_
     - 帳票出力時に利用するテンプレートIDを指定します。
   * - fileItmTmpltId [#doption]_
     - ファイル出力時に選択されるファイル出力項目テンプレートIDを設定します。  

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
