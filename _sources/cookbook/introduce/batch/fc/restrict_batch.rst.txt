===================================================
入力制限ジョブ実行
===================================================
以下は、入力制限ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_fc_restrict
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DdepartmentCd=10000 -DisSubordinateDepartment=1
  -DexceptDepartmentCdList=11110 -DexecutionModule=lc
  -DdateDif=30


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - departmentCd [#doption]_
     - 入力制限を行う組織コードを指定します。
   * - isSubordinateDepartment [#doption]_
     - 指定した組織コードの配下組織にも同様の処理をするかを表すフラグを指定します。

       0：処理をしない、1：処理をする
   * - exceptDepartmentCdList [#doption]_
     - 除外する組織コードのリスト（複数設定可）を指定します。 [#isSubordinateDepartment]_
   * - executionModule [#doption]_
     - 入力制限を行うモジュール分類を指定します。

       gl（一般会計）、ap（債務管理）、ar（債権管理）、ma（管理会計）、fe（外貨管理）、bn（手形管理）、fa（資産管理）、lc（契約管理・リース管理）のいずれかを指定します。
   * - dateDif [#doption]_
     - 営業日における、バッチが起動した日付と、設定する入力制限最終日の差を数値で指定します。
  

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
.. [#isSubordinateDepartment] 指定した組織コードと配下組織フラグによって取得された複数の組織から、指定された組織を除きます。

         除外組織コードリストはカンマ区切りで指定します。処理の中でカンマ区切りをリスト形式に変換して使用します。

         指定不要の場合は登録不要です。
