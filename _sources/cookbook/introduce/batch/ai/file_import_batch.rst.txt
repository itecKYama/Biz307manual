===================================================
連携ファイル取込処理のジョブ実行
===================================================
以下は、連携ファイル取込処理のジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_ai_fileImport
  -certUserCd=B12200 -certUserPassword=PASSWORD 
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DcreateApplicationType=sms -DcreateApplicationCategory=slar
  -Dbapf.batch.exitStatus.warn=3 -Dbapf.batch.exitStatus.warn.jobStatus=WARNING
  -Dbapf.batch.exitStatus.warn.rollback=false


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - createApplicationType [#doption]_
     - :ref:`FMS_introduce_module_ai-preparation_ai` で定めた作成アプリケーションを指定します。
   * - createApplicationCategory [#doption]_
     - :ref:`FMS_introduce_module_ai-preparation_ai` で定めた作成アプリケーション分類を指定します。
   * - bapf.batch.exitStatus.warn [#doption]_
     - 3を指定します。
   * - bapf.batch.exitStatus.warn.jobStatus [#doption]_
     - WARNINGを指定します。
   * - bapf.batch.exitStatus.warn.rollback [#doption]_
     - falseを指定します。

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
