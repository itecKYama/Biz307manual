===================================================
マテリアライズドビュー更新のジョブ実行
===================================================
以下は、マテリアライズドビュー更新のジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_ef_MaterializedViewUpdate
  -certUserCd=B12200 -certUserPassword=PASSWORD 
  -url=http://localhost:8080/imart/HTTPActionEventListener
  -DviewKind=1 -DviewName=FMS_EF_V_FACT_BLC
  -DbaseDate=20210401

設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - 外部ソフトウェア接続URLを指定します。

       http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - viewKind [#doption]_
     - ビューの種類単位でマテリアライズド・ビューを更新する場合に設定します。 [#param]_

       ビュー種類は以下となります。

       　1.ファクト

       　2.ディメンション

       　3.データマート
   * - viewName [#doption]_
     - マテリアライズド・ビューのオブジェクト名を指定して更新する場合に設定します。 [#param]_
   * - baseDate [#doption]_
     - マテリアライズド・ビューを特定の日の情報で更新する場合に設定します。

       任意

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。

.. [#param] いずれか片方のみの設定でも動作します。
