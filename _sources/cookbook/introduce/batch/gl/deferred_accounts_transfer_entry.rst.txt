===================================================
経過勘定振替ジョブ実行
===================================================
以下は、経過勘定振替ジョブをコマンドラインから実行するコマンド例です。

コマンド例（1行で記述します） ::

  java -jar %バッチ処理ブートストラップ%
  -tenantId=default -jobnetId=fms_gl_deferredAccountsTransferEntry
  -certUserCd=B12200 -certUserPassword=PASSWORD
  -url=http://localhost:8080/imart/HTTPActionEventListeners
  -DprocessMode=1 -Dclosing=0
  -DdepartmentGroupCd=G12200 -DdepartmentCd=12200


設定パラメータ

.. list-table::
   :widths: 5, 20
   :header-rows: 1

   * - パラメータ
     - 説明
   * - tenantId
     - 外部ソフトウェア接続を利用する際の認証に利用するテナントIDを指定します。
   * - jobnetId
     - :ref:`FMS_cookbook_introduce_batch-job` で登録したジョブネットIDを指定します。
   * - certUserCd
     - 外部ソフトウェア接続認証に利用するユーザコードを指定します。
   * - certUserPassword
     - 外部ソフトウェア接続を利用する際の認証に利用するパスワードを指定します。
   * - url
     - | 外部ソフトウェア接続URLを指定します。
       | http://<ホスト名>:<ポート>/ imart/HTTPActionEventListenerを指定します。
   * - processMode [#doption]_
     - | 仕訳の作成方法を指定します。
       | 1：仮実行 2：仮実行+本実行
   * - closing [#doption]_
     - | 未収未払振替のする／しないを指定します。
       | 0.未収・未払振替しない
       | 1.未収・未払振替する
   * - departmentGroupCd [#doption]_
     - 本支店組織グループコードを指定します。
   * - departmentCd [#doption]_
     - 起票組織コードを指定します。

.. rubric:: 注釈

.. [#doption] -Dオプションでパラメータを引き渡します。
