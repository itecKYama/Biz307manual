===================================================
区分記載請求書に変更する
===================================================

区分記載請求書のレイアウトで運用する場合に、請求書の帳票設定を変更します。

前提条件
===================================================

区分記載請求書の帳票レイアウトファイルが帳票サーバに配置されていること。

  ::

    フォームルートディレクトリ/form/biz_integral/fms/default/layout/pr/ja/invoice_classification1.xml
    フォームルートディレクトリ/form/biz_integral/fms/default/layout/pr/ja/invoice_classification2.xml
  

実行手順
===================================================

1. パラメータ「請求明細の合計行出力要否」を「1:出力要」に変更します。

  1.1 Biz∫会計管理者アカウントでポータル画面にログインし、以下のメニューを開きます。
  
    * メニュー ::
    
        Biz∫会計
          会計コア
            基本設定管理
              パラメータ管理

  1.2 以下の条件で「F6:検索」ボタンを押下します。
  
    * 対象モジュール：債権債務
  
  1.3 パラメータ「請求明細の合計行出力要否」を「1:出力要」に変更します。
  


2. 帳票レイアウトを変更する。

  2.1 以下のメニューを開きます。
  
    * メニュー ::
    
        Biz∫ APF アドミニストレーション 
          システム管理
            帳票設定
              帳票設定


  2.2 以下の条件で「F6:検索」ボタンを押下します。

    * アプリケーションID：fms

    * モジュールID：pr

    * 帳票コード：invoice


  2.3 帳票コードがinvoiceのレコードの更新ボタンを押下します。

  2.4 帳票レイアウトファイルパスを以下のように変更し、「F5:登録」ボタンを押下します。

    ::

      form/biz_integral/fms/default/layout/pr/ja/invoice_classification1.xml



完了条件
===================================================

請求書出力画面にて、「請求明細合計行」チェックボックスが利用できることを確認します。

請求書を出力し、帳票レイアウトが変わっていることを確認します。
