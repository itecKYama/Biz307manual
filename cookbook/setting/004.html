ファイル入出力の設定を変更する¶

ファイル入出力における設定を行います。

コラム

出荷時の設定のままでも動作します。導入するシステム要件に応じて、必要であれば変更を行ってください。

前提条件¶

  • 以下の設定は、Biz∫会計が提供する機能についての設定値です。

    他のアプリケーション(機能及び設定)については、各アプリケーションのドキュメント等を参照してください。

  • ファイルの削除期限日の設定は、ファイル管理クリーンアップ処理にてファイル削除対象の条件として利用されます。

    ファイル管理クリーンアップ処理については、Biz∫APFのアドミニストレーションクリーンアップリファレンスを参照して下さい。

ファイル入出力に関する設定¶

ファイル入出力に関する設定を変更する場合は、ファイルフォーマット設定テーブル（biz_file_format_config）の以下の値を直接変更します。以下の説明を参考に設定値を決定してください。

列名

設定値

備考

file_format

ファイルフォーマットを設定します。

CSV / TSV

Biz∫会計ではEXCEL出力時に本テーブルは利用していません。また、Biz∫会計では初期設定から変更して運用することは想定していません。

encoding

ファイルフォーマットを設定します。

Windows-31J (出荷時の設定) / UTF-8

file_formatが'CSV'である値が以下の制御箇所での初期表示設定値として利用されます。

■制御箇所

一括登録実行ダイアログ、ファイル出力実行ダイアログ、仕訳一括取込、一括取込（債権債務）、資産一括取込、設備投資資産一括取込、一括取込ファイル作成、プロジェクト別組織変更実行、プロジェクト計画一括取込、プロジェクト一括取込、予算取込

font

ファイル出力時のフォントをを設定します。

Biz∫会計では利用していません。EXCEL出力時は「MSゴシック」になります。

separatort

ファイル出力時の区切り文字を設定します。

Biz∫会計では初期設定から変更して運用することは想定していません。

quote_character

ファイル出力時の囲み文字を設定します。

record_separator

ファイル出力時のレコード終端文字を設定します。

Biz∫会計では利用していません。また、Biz∫会計では初期設定から変更して運用することは想定していません。

line_separator

ファイル出力時のフィールド終端文字を設定します。

CRLF（出荷時の設定）/ CR / LF

escape_character

ファイル出力時のエスケープ文字を設定します。

delete_flag

削除フラグを設定します。

0（固定）

version_no

バージョン番号を設定します。情報管理用の項目であり、処理には利用していません。

create_user_cd

作成者を設定します。情報管理用の項目であり、処理には利用していません。

create_date

作成日を設定します。情報管理用の項目であり、処理には利用していません。

record_user_cd

最終更新者を設定します。情報管理用の項目であり、処理には利用していません。

record_date

最終更新日を設定します。情報管理用の項目であり、処理には利用していません。

コラム

Biz∫会計では初期設定のレコードのみ利用します。レコードを追加しても反映されません。

また、本テーブルはBiz∫販売でも利用しているため、変更はBiz∫販売の処理にも反映されます。両方導入しているシステムでは注意してください。

ストレージファイルに関する設定¶

ストレージファイルに関する設定は、ストレージファイル管理設定テーブル（biz_storage_file_config）の設定値を変更、またはレコードを追加します。

列の値は以下を参考に設定します。

列名

設定値

備考

company_cd

会社コードを設定します。

application_id

アプリケーションIDを設定します。

Biz∫会計では'fms'となります。

module_id

モジュールIDをを設定します。

ストレージファイルに設定が反映される優先順位を参考に、必要に応じて設定します。

usage

用途を設定します。

REPORT / UPLOAD_FILE / ATTACHED_UPLOAD_FILE

各値は以下のタイミングで利用されます。

REPORT：ファイル出力時

UPLOAD_FILE：添付ファイル登録ダイアログ以外のファイルアップロード時

ATTACHED_UPLOAD_FILE：添付ファイル登録ダイアログでファイルアップロード時

category

カテゴリを設定します。

ストレージファイルに設定が反映される優先順位を参考に、必要に応じて設定します。

expired_days

ファイルの保存日数を設定します。

「システム日付+設定値」が保持期限日として設定されます。保持期限日を過ぎたファイルはダウンロードができなくなります。

usageが'UPLOAD_FILE'の場合、本設定が削除期限日としても設定されます。

usageが'ATTACHED_UPLOAD_FILE'の場合、ファイルを添付した仕訳・取引・資産が申請されればこの設定値とは無関係に有効期限は無期限になります。

delete_days

ファイルの削除日数を設定します。

「システム日付+設定値」が削除期限日として設定されます。

削除期限日を過ぎると、APFクリーンアップ機能の対象となります。保持期限日から削除期限日までの間は、ファイルはストレージサービス上に残っています(クリーンアップ対象外)が、画面からファイルを参照することができなくなります。

usageが'UPLOAD_FILE'の場合、本設定は利用していません。

usageが'ATTACHED_UPLOAD_FILE'の場合、ファイルを添付した仕訳・取引・資産が申請されればこの設定値とは無関係に有効期限は無期限になります。

delete_flag

削除フラグを設定します。

0（固定）

version_no

バージョン番号を設定します。情報管理用の項目であり、処理には利用していません。

create_user_cd

作成者を設定します。情報管理用の項目であり、処理には利用していません。

create_date

作成日を設定します。情報管理用の項目であり、処理には利用していません。

record_user_cd

最終更新者を設定します。情報管理用の項目であり、処理には利用していません。

record_date

最終更新日を設定します。情報管理用の項目であり、処理には利用していません。

ストレージファイルに設定が反映される優先順位¶

帳票単位またはモジュール単位に設定を変更したい場合は、以下を参考にレコードを追加します。

コラム

帳票単位またはモジュール単位での設定を可能としていますが、設定が不要であればレコードを追加する必要はありません。

  • usageが「REPORT」の場合

複数設定されている場合は、以下の優先度で設定が有効となります。(番号が大きいほうが優先度高)

  1. デフォルト（アプリケーション単位）

初期設定されています。

  1. デフォルト（モジュール単位）

application_id：'fms'　module_id：'[モジュールID]'　category：'fms.[モジュールID].default'のレコードを追加します。

  1. 帳票単位

application_id：'fms'　module_id：'[モジュールID]'　category：'fms.[モジュールID].[帳票ID]'のレコードを追加します。

  • usageが「UPLOAD_FILE」「ATTACHED_UPLOAD_FILE」の場合

    複数設定されている場合は、以下の優先度で設定が有効となります。(番号が大きいほうが優先度高)

    1. デフォルト（アプリケーション単位）

    初期設定されています。

    1. デフォルト（モジュール単位）

    application_id：'fms'　module_id：'[モジュールID]'　category：'fms.[モジュールID].default'のレコードを追加します。

ファイル出力や帳票出力時の論理ファイル名に関する設定¶

ファイル出力時の以下の論理名を変更する場合は、名称テーブル（biz_named_item）の名称（item_name）を変更します。

  • ファイルダウンロードダイアログ上に表示

  • ダウンロード時のファイル名に付与

コラム

初期設定として以下レコードが設定されています。

アプリケーションID（application_id）：'fms'

モジュールID（module_id）：'[モジュールID]'

名称ID（item_id）：'FMS.[モジュールID（大文字）].[帳票ID].file'

帳票出力時のファイル論理名を変更する場合は、以下メニューより帳票ファイル表示名を変更します。

  • メニュー

    Biz∫ APF アドミニストレーション
  システム管理
    帳票設定
      帳票設定

ファイル出力や帳票出力時のクエリに関する設定¶

ファイル出力や帳票出力時に利用するクエリファイルを別のファイルに変更する場合は、帳票クエリテーブル（biz_report_query）のクエリファイルパス（path）を変更します。

コラム

初期設定として以下レコードが設定されています。

アプリケーションID（application_id）：'fms'

モジュールID（module_id）：'[モジュールID]'

クエリコード（query_cd）：'fms.[モジュールID].[帳票ID]'（帳票出力の場合） または'fms.[モジュールID].[帳票ID].file'（ファイル出力の場合）
