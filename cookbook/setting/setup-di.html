Biz∫APFデータ連携の設定をする¶

Biz∫APFデータ連携のマスタ設定およびデータベース・リンクの作成を行います。

コラム

Biz∫APFデータ連携のマスタ登録画面の操作方法については、Biz∫APFのBiz∫データ連携モジュール操作ガイドを参照してください。

前提条件¶

  • Biz∫APFデータ連携のインストールが完了していること。

実行手順¶

データベースを登録する¶

Biz∫APFデータ連携のタスクで利用するデータベースを登録します。

  • メニュー

    Biz∫ APF データ連携
  マスタ管理
    データベース管理

  • 設定内容

    コラム

    テナントデータベースおよびシェアードデータベースを登録します。

    複数テナントに導入している場合、全てのテナントデータベースを登録してください。

    項目

    設定値

    データベースコード
    ・テナントデータベースの場合

    テナントID

    ・シェアードデータベースの場合

    shared

    接続ID

    IM-Jugglingプロジェクト内の設定ファイル「data-source-mapping-config.xml」に指定した接続ID

    ・テナントデータベースの場合

    tenant-data-source/tenant-idに指定した値

    ・シェアードデータベースの場合

    shared-data-source/connect-idに指定した値

テナントを登録する¶

データ連携を行うテナントを登録します。

  • メニュー

    Biz∫ APF データ連携
  マスタ管理
    テナント管理

  • 設定内容

    項目

    設定値

    テナントID

    データ連携を行うテナントのテナントID

データ連携を行う会社を登録します。

    名称・略称・検索名

    任意の値

データベース・リンクを作成する¶

テナントデータベースからシェアードデータベースへのアクセスにOracleデータベース・リンクを利用しない場合、本手順は不要です。

コラム

データベース・リンクを利用する場合、Biz∫APFデータ連携の「OracleJdbcLoaderサブスクライブタスク」のマスタにデータベース・リンクを設定します。

複数テナントに導入している場合、全てのテナントユーザに対して実施してください。

  1. 管理者ユーザでデータベースにログインします。

  2. 次のSQLを実行し、テナントユーザに対してデータベース・リンクを作成する権限を付与します。ユーザ名は環境に合わせて変更してください。

GRANT CREATE DATABASE LINK TO iap_tenant;

  1. テナントユーザでデータベースにログインします。

  2. 次のSQLを実行し、データベース・リンクを作成します。データベース・リンク名、ユーザ名、パスワード、ホスト、ポート番号、ServiceName名は環境に合わせて変更してください。

CREATE DATABASE LINK dblink
CONNECT TO iap_tenant_shared
IDENTIFIED BY XXXXXXXX
USING '(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=127.0.0.1)(PORT=1521))(CONNECT_DATA=(SERVICE_NAME=orcl)))';

科目マスタの取込ワークロードを実施する¶

コラム

本章はPostgreSQLを利用する場合の対応となります。

科目マスタの取込ワークロード(FMS.FC.ACCOUNT_SUB_WKLD_{テナントID}_{会社コード})のステップに科目ビューのリフレッシュタスクを追加します。

  • メニュー

    Biz∫ APF データ連携
  マスタ管理
    ワークロード管理

  • 設定内容

    項目

    設定値

    実行順

    既存ステップの実行順の最大値+1

    タスクコード

    FMS.FC.V_ACCOUNT_DML_POSTGRE_{テナントID}

    ステップ名

    任意
