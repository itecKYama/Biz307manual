連携誤り・漏れのリカバリ手順¶

グループ会社間取引連携実行後に生じる、法人・取引先マスタの設定誤り・漏れによる連携誤り・漏れのリカバリを行います。

実行手順¶

連携誤り¶

誤った法人コードが設定された取引先コードで債権登録を行ったことにより、誤った会社へ債権が連携された場合のリカバリ手順です。

訂正によるリカバリ手順¶

以下の手順で債権の再計上または修正を行います。

  • 法人・取引先マスタの設定を変更する。手順については法人グループ、法人・取引先マスタの登録を参照してください。

  • 計上済の債権について、削除して再登録、または、修正を行う。

  • 再度グループ会社間取引連携を実行する。

DBパッチによるリカバリ手順¶

債権の内容に変更がなく、債権の訂正が許容できない場合、DBパッチによりリカバリを行います。

  • 仕訳明細検索等により、誤って連携した仕訳の仕訳IDを確認します。

  • 誤って連携した債務基礎情報をDBパッチにて削除してください。

次のsqlは、誤って連携した債務基礎情報を削除する場合の例文です。

DELETE FROM fms_gt_ap_base_info
WHERE src_company_cd = 'DEFAULT_COMPANY'  ---債権会社の会社コードを指定してください。
AND   src_journal_id = 9999998            ---誤って連携した債権の仕訳IDを指定してください。

  • 法人・取引先マスタの設定を変更する。手順については法人グループ、法人・取引先マスタの登録を参照してください。

  • 誤って連携した債権債務伝票の「債権連携区分」をDBパッチにて「未連携」に更新する。

  • 再度グループ会社間取引連携を実行する。

次のsqlは、取引先コード単位で債権債務伝票の「債権連携区分」を「未連携」に更新する場合の例文です。

UPDATE fms_pr_slip
SET ar_cprtn_type = '1'
WHERE company_cd = 'DEFAULT_COMPANY'
AND customer_cd = '1000000000'

連携漏れ¶

グループ会社間取引連携対象外の法人コードが設定された取引先コード、または、法人コードが未設定の取引先コードで債権登録を行ったことにより、債権が連携されなかった場合のリカバリ手順です。

  • 法人・取引先マスタの設定を行う。手順については法人グループ、法人・取引先マスタの登録を参照してください。

  • グループ会社間取引の連携対象となる債権債務伝票の「債権連携区分」をDBパッチにて「未連携」に更新する。グループ会社間取引以外については、「対象外」に更新する。

  • グループ会社間取引連携を実行する。

次のsqlは、取引先コード単位で債権債務伝票の「債権連携区分」を「対象外」に更新する場合の例文です。

UPDATE fms_pr_slip
SET ar_cprtn_type = '2'
WHERE company_cd = 'DEFAULT_COMPANY'
AND customer_cd = '2000000000'
