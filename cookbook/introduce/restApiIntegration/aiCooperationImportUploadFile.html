仕訳情報をBiz∫会計にファイル連携する¶

連携元システムから連携対象のデータを出力したファイルの内容をREST APIを使用して会計連携テーブルに登録する方法を説明します。

前提条件¶

  • 会計連携取込設定管理が完了していること。

    • 「連携するデータがファイルの場合」を実施していること。

実行手順¶

連携方法は以下のとおりです。

実行順

概要

REST API
HTTP
メソッド

パス

パラメータ

1

連携ファイルアップロード

共有ストレージサービスREST API >アップロード

POST

/api/v1/biz/cc/sharedStorages/upload

file [1]

2

連携ファイル取込

会計連携テーブルREST API >アップロードファイル取込

POST

/api/v1/fms/ai/cooperation/importUploadFile
fileUploadContextId [2]
createApplicationType [3]
createApplicationCategory [4]
[1]

連携元システムから出力したファイルを指定します。

コラム

アップロードできる最大ファイルサイズの初期値は10MBです。
上限値は${RESIN_HOME}/webapps/imart/WEB-INF/conf/request-control-config.xmlのリクエストクエリの長さ制限から変更できます。
[2]

実行順1の戻り値であるファイルアップロードコンテキストIDを指定します。

[3]

会計連携取込設定管理で登録した作成アプリケーションを指定します。

[4]

会計連携取込設定管理で登録した作成アプリケーション分類を指定します。

cURLコマンドを利用したREST API実行例¶

  1. 連携ファイルアップロード

コマンド例

curl -X POST -F file=@./sample.csv -u B12200:PASSWORD http://localhost:8080/imart/basic/api/v1/biz/cc/sharedStorages/upload

  1. 連携ファイル取込

コマンド例

curl -X POST -H "Content-Type: application/json" -u B12200:PASSWORD http://localhost:8080/imart/basic/api/v1/fms/ai/cooperation/importUploadFile -d "{\"fileUploadContextId\": \"f3f3222ac6ad4221ad926f148398315c\", \"createApplicationType\": \"smp\", \"createApplicationCategory\": \"up\"}"
